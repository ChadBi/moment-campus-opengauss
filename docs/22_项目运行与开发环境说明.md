## 3. 后端启动方式

### 3.1 一次性环境准备（首次运行）

```powershell
# 1. 进入后端目录
cd d:\Project\database-class\moment-campus\backend

# 2. 创建虚拟环境（强制命名为 .venv，依据 AGENTS.md）
python -m venv .venv

# 3. 激活虚拟环境（Windows PowerShell）
.\.venv\Scripts\Activate.ps1
# 若提示执行策略错误，先执行：Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

# 4. 升级 pip
python -m pip install --upgrade pip

# 5. 安装依赖
pip install -r requirements.txt
```

**macOS/Linux** 激活命令：`source .venv/bin/activate`

### 3.2 配置环境变量

```powershell
# 复制配置模板
Copy-Item .env.example .env.development
```

编辑 `.env.development`，关键配置项（参考 [backend/.env.example](file:///d:/Project/database-class/moment-campus/backend/.env.example)）：

```ini
APP_NAME=此刻校园
DEBUG=True
API_V1_PREFIX=/api/v1

# SQLite 模式（默认）
DATABASE_URL=sqlite+aiosqlite:///./dev.db

# JWT 配置
SECRET_KEY=dev-secret-key-do-not-use-in-production
ACCESS_TOKEN_EXPIRE_MINUTES=30
REFRESH_TOKEN_EXPIRE_DAYS=7
ALGORITHM=HS256

# 文件上传
UPLOAD_DIR=./uploads
MAX_UPLOAD_SIZE=5242880

# CORS
CORS_ORIGINS=["http://localhost:5173"]

# 日志
LOG_LEVEL=DEBUG
```

### 3.3 初始化数据库（SQLite 模式）

**重要发现**：当前 Alembic 初始迁移为空（只有 `pass`），无法通过 `alembic upgrade head` 建表。详见 [20_openGauss适配分析.md](file:///d:/Project/database-class/moment-campus/docs/20_openGauss适配分析.md) 第 9 节。

**当前可用方式（直接通过 seed_data.py 建表）**：

```powershell
# 在 backend 目录下，激活 .venv
python scripts\seed_data.py
```

`seed_data.py` 中的 `init_db()` 函数会调用 `Base.metadata.create_all(engine)` 直接建表并填充演示数据。

**待 T-A-08 完成后的方式**：

```powershell

# 填充演示数据
```

### 3.4 启动后端服务

```powershell

uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

启动后访问：
- API 服务：http://localhost:8000
- OpenAPI 文档：http://localhost:8000/docs
- 健康检查：http://localhost:8000/health

## 5. openGauss Docker 启动方式

### 5.1 前置条件检查

```powershell
# 1. 确认 Docker Desktop 已启动
docker --version

# 2. 确认本地已导入 openGauss 镜像（重要：pull_policy: never）
docker images | findstr opengauss
# 预期输出：opengauss   7.0.0-RC3   <image_id>   ...
```

**若镜像不存在**：需从 [openGauss 官方下载页](https://opengauss.org/zh/download/) 获取 7.0.0-RC3 轻量版离线镜像包，并通过 `docker load -i <文件路径>` 导入。T-A-01 已确认本地导入完成。

### 5.2 启动 openGauss 容器

```powershell
# 在项目根目录
cd d:\Project\database-class\moment-campus

# 后台启动 openGauss 服务
docker compose up -d opengauss

# 查看容器状态
docker ps
# 预期：opengauss   Up   0.0.0.0:5432->5432/tcp
```

### 5.3 首次启动等待

openGauss 首次启动需初始化数据库（约 10–30 秒）。可通过日志判断是否就绪：

```powershell
docker logs -f opengauss
# 看到 "database system is ready to accept connections" 表示就绪
```

按 `Ctrl+C` 退出日志查看（不会停止容器）。

### 5.4 验证 openGauss 连接

```powershell
# 在容器内执行 gsql 查询版本
docker exec opengauss gsql -d moment_campus -U gaussdb -W Gaussdb@123 -c "SELECT version();"

# 查看当前数据库
docker exec opengauss gsql -d moment_campus -U gaussdb -W Gaussdb@123 -c "SELECT current_database();"

# 查看当前 schema
docker exec opengauss gsql -d moment_campus -U gaussdb -W Gaussdb@123 -c "SELECT current_schema();"

# 查看时区
docker exec opengauss gsql -d moment_campus -U gaussdb -W Gaussdb@123 -c "SHOW timezone;"
```

### 5.5 openGauss 容器管理常用命令

```powershell
# 停止
docker compose stop opengauss

# 启动（已创建）
docker compose start opengauss

# 重启
docker compose restart opengauss

# 完全删除容器（保留数据卷）
docker compose down opengauss

# 完全删除容器 + 数据卷（⚠️ 数据丢失）
docker compose down -v opengauss
```

### 5.6 数据持久化说明

- 数据卷名：`opengauss-data`
- 容器内路径：`/var/lib/opengauss`
- 即使 `docker compose down` 删除容器，数据卷仍保留
- 仅 `docker compose down -v` 会删除数据卷

## 6. 数据库连接方式

### 6.1 SQLite（默认开发模式）

| 项 | 值 |
| -- | -- |
| 类型 | SQLite（异步） |
| 连接字符串 | `sqlite+aiosqlite:///./dev.db` |
| 驱动 | aiosqlite |
| 文件位置 | `backend/dev.db`（运行后生成） |
| 可视化工具 | DBeaver、Navicat、VS Code SQLite 插件 |

### 6.2 openGauss（目标模式）

| 项 | 值 |
| -- | -- |
| 类型 | openGauss 7.0.0-RC3 轻量版 |
| 主机 | localhost（容器外） / opengauss（容器内） |
| 端口 | 5432 |
| 数据库名 | moment_campus |
| 用户名 | gaussdb |
| 密码 | Gaussdb@123 |
| 连接字符串（应用层） | `postgresql+asyncpg://gaussdb:Gaussdb%40123@localhost:5432/moment_campus` |
| 驱动 | asyncpg（T-A-03/T-A-05 已验证并接入 requirements.txt） |
| 可视化工具 | DBeaver（PostgreSQL 模式）、Navicat |

### 6.3 在 DBeaver 中连接 openGauss

1. 新建连接 → 选择 PostgreSQL
2. Host: `localhost`
3. Port: `5432`
4. Database: `moment_campus`
5. Username: `gaussdb`
6. Password: `Gaussdb@123`
7. **重要**：在 Driver Properties 中添加 `ssl=false` 或 `sslmode=disable`

### 6.4 数据库连接信息来源

所有连接信息严格来自 [docker-compose.yml](file:///d:/Project/database-class/moment-campus/docker-compose.yml)，**未参考 README**（README 中 PostgreSQL 描述与实际不符）。

## 11. 常见问题

### 11.1 后端启动报错

#### Q1：`ModuleNotFoundError: No module named 'fastapi'`

**原因**：未激活虚拟环境或未安装依赖。

**解决**：
```powershell
cd backend
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

#### Q2：`ImportError: No module named 'asyncpg'`

**原因**：T-A-05 未完成，或缺该依赖。

**解决**：执行 T-A-05（在 requirements.txt 添加 asyncpg 并 pip install）。

#### Q3：`alembic upgrade head` 没建任何表

**原因**：当前初始迁移文件为空（只有 `pass`），详见 doc 20 第 9 节。

**解决**：直接用 `python scripts\seed_data.py` 建表；或等 T-A-08 完成后重写迁移。

#### Q4：`SQLAlchemy: No module named 'aiosqlite'`

**原因**：未安装异步 SQLite 驱动。

**解决**：`pip install aiosqlite`

#### Q5：登录返回 401 Unauthorized

**原因**：密码错误，或 SECRET_KEY 不一致。

**解决**：
- 确认密码为 `pass123`
- 若重新生成 SECRET_KEY，需重新执行 seed_data.py（密码 hash 会失效）

### 11.2 前端启动报错

#### Q6：`npm install` 失败

**原因**：网络问题或 Node.js 版本过低。

**解决**：
- 升级 Node.js 到 18+
- 使用淘宝镜像：`npm config set registry https://registry.npmmirror.com`
- 删除 `node_modules` 和 `package-lock.json` 后重试

#### Q7：前端能打开但显示"网络错误"

**原因**：后端未启动，或 CORS 配置错误。

**解决**：
- 确认后端运行在 http://localhost:8000
- 检查 `.env.development` 中 `CORS_ORIGINS` 包含 `http://localhost:5173`

#### Q8：TypeScript 编译错误

**原因**：可能移除了 `ignoreDeprecations: "6.0"` 配置。

**解决**：恢复 [frontend/tsconfig.app.json](file:///d:/Project/database-class/moment-campus/frontend/tsconfig.app.json) 中的 `ignoreDeprecations: "6.0"`。

### 11.3 openGauss 容器问题

#### Q9：`docker compose up` 报 `image not found`

**原因**：`pull_policy: never` 但本地未导入镜像。

**解决**：执行 T-A-01（导入 openGauss 镜像）。

#### Q10：`docker exec ... gsql` 报 `password authentication failed`

**原因**：密码输入错误。

**解决**：确认密码为 `Gaussdb@123`（注意大小写与特殊字符）。

#### Q11：openGauss 容器启动后立即退出

**原因**：可能数据卷已损坏。

**解决**：
```powershell
docker compose down -v opengauss   # ⚠️ 删除数据卷
docker compose up -d opengauss
```

#### Q12：asyncpg 连接报 `SSL` 相关错误

**原因**：openGauss 默认 SSL 配置可能与 asyncpg 不兼容。

**解决**：在 DATABASE_URL 末尾添加 `?sslmode=disable`：
```
postgresql+asyncpg://gaussdb:Gaussdb%40123@localhost:5432/moment_campus?sslmode=disable
```

### 11.4 PowerShell 执行策略问题

#### Q13：`Activate.ps1 cannot be loaded because running scripts is disabled`

**原因**：PowerShell 默认禁止执行脚本。

**解决**：
```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
# 输入 Y 确认
```

### 11.5 端口冲突

#### Q14：端口 8000/5173/5432 被占用

**排查**：
```powershell
netstat -ano | findstr :8000
# 找到 PID 后
taskkill /PID <PID> /F
```

或修改对应配置文件中的端口。
