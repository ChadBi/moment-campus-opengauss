# 项目运行与开发环境说明

> 文档版本：2.0
> 现行口径同步：2026-07-31
> 适用范围：“此刻校园”本地开发、测试与生产定时任务

## 1. 当前运行基线

项目只支持前后端分离运行，openGauss 7.0.0-RC3 轻量版是唯一数据库。SQLite、`dev.db`、`aiosqlite` 和 SQLite 测试模式均已移除，不得作为开发或测试备选方案。

| 组件 | 当前方案 | 默认地址 |
|---|---|---|
| Web 前端 | React + TypeScript + Vite | `http://localhost:5173` |
| API 后端 | FastAPI + Uvicorn | `http://localhost:8000` |
| 数据库 | openGauss 7.0.0-RC3 轻量版 | `127.0.0.1:5432` |
| API 文档 | FastAPI OpenAPI | `http://localhost:8000/docs` |
| 自动过期 | systemd timer + oneshot worker | 启动后 5 分钟首次执行，此后每 30 分钟 |

Python 命令必须使用 `backend/.venv` 虚拟环境。数据库容器通过项目根目录的 `docker-compose.yml` 启动，镜像策略以仓库现行配置为准。

## 2. 环境要求

| 软件 | 建议版本 | 用途 |
|---|---|---|
| Python | 3.11+ | FastAPI、脚本和测试 |
| Node.js | 20 LTS | 前端开发与构建 |
| npm | 10+ | 前端依赖管理 |
| Docker Desktop | 24+ | openGauss 容器 |
| Docker Compose | v2.20+ | 数据库编排 |
| Git | 2.30+ | 版本管理 |

常用端口为前端 `5173`、后端 `8000`、openGauss `5432`。修改端口时同步检查前端 API 地址、CORS 和数据库连接串。

## 3. 首次准备

在项目根目录启动 openGauss：

```powershell
docker compose up -d opengauss
docker compose ps
```

准备后端虚拟环境：

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

准备前端依赖：

```powershell
cd frontend
npm install
```

## 4. 后端配置与启动

本地运行使用 openGauss 环境：

```powershell
cd backend
.\.venv\Scripts\Activate.ps1
$env:APP_ENV = "opengauss"
uvicorn app.main:app --reload
```

数据库连接、JWT、CORS 和 AI Provider 配置以 `backend/.env.opengauss.example` 为模板。实际密钥只写入本地环境文件或服务器环境变量，不得写入文档、前端代码、日志或提交记录。

初始化或刷新演示数据时使用同一虚拟环境：

```powershell
cd backend
.\.venv\Scripts\Activate.ps1
$env:APP_ENV = "opengauss"
python scripts\seed_data.py
```

演示数据以江南大学为主，附带复旦大学和浙江大学用于多租户切换演示。

## 5. 前端启动

```powershell
cd frontend
npm run dev
```

前端分类必须从当前学校的 `/api/v1/categories` 动态加载，不得新增固定分类 ID 或中文名称映射。分类图标和颜色通过 `category.code` 稳定计算；切换学校时需要同步清理旧校分类、筛选状态和地图标记。

## 6. AI 搜索与降级

AI 搜索先解析自然语言意图，再在当前租户的公开、未删除、未过期帖子中执行结构化条件检索。配置可用 Embedding Provider 时，系统使用 openGauss 原生 DataVec：

- 帖子向量维度为 384；
- 使用 DataVec 向量距离进行语义候选召回；
- 混合排序权重为语义 35%、新鲜度 25%、协同验证数 20%、关键词相关度 20%；
- Embedding 生成失败、向量缺失或向量查询异常时自动降级为关键词检索；
- 降级不阻断普通搜索、分类筛选和地图浏览。

历史帖子向量回填使用：

```powershell
cd backend
.\.venv\Scripts\Activate.ps1
$env:APP_ENV = "opengauss"
python scripts\generate_embeddings.py
```

## 7. 协同验证契约

现行协同验证只接受两类值：

- `confirmation`：证实；
- `refutation`：证伪。

单数写端点为 `POST /api/v1/posts/{post_id}/validate`。每名用户对每条帖子只保留一条记录：首次提交创建，提交另一类型切换，再次提交同类型取消；作者不能验证自己的帖子。

登录用户可通过 `GET /api/v1/posts/{post_id}/validation-stats` 获取两类计数和本人当前选择，帖子详情响应的 `governance` 字段提供公开聚合。历史复数 `/validations`、`/validity` 以及 `update`、`expiration_report`、`conflict_report` 均不属于现行契约。

## 8. 自动过期任务

生产环境不在 Uvicorn Web worker 内启动调度器。独立 `moment-expire-posts.timer` 在系统启动后 5 分钟首次触发 `moment-expire-posts.service`，此后每 30 分钟触发一次，由 oneshot worker 扫描到期的 `published` 帖子并按状态机转为 `expired`。

任务具备数据库 advisory lock、60 分钟运行租约和幂等通知保护。手动触发任务及查询运行记录只允许 `super_admin`。部署文件位于：

- `deploy/bare-metal/moment-expire-posts.service`
- `deploy/bare-metal/moment-expire-posts.timer`
- `backend/scripts/expire_posts_worker.py`

常用服务端检查命令：

```bash
sudo systemctl status moment-expire-posts.timer
sudo systemctl list-timers moment-expire-posts.timer
sudo journalctl -u moment-expire-posts.service -n 100 --no-pager
```

## 9. 独立测试库

后端测试必须连接独立 openGauss 测试库，不得回退到开发库或生产库。测试夹具在清理数据前执行三项硬校验：

1. 必须设置 `TEST_DATABASE_URL`；
2. URL 中的数据库名必须包含 `_test`；
3. `TEST_DATABASE_URL` 不得与开发库 `DATABASE_URL` 相同。

PowerShell 示例：

```powershell
cd backend
.\.venv\Scripts\Activate.ps1
$env:APP_ENV = "opengauss"
$env:TEST_DATABASE_URL = "postgresql+asyncpg://<user>:<password>@127.0.0.1:5432/moment_campus_test"
pytest tests/ -v
```

示例中的凭据必须替换为本地安全配置，不得把真实密码写入文档或提交记录。测试会重建测试库 `public` schema 并清理表数据，因此数据库名保护是强制门禁。

前端构建验证：

```powershell
cd frontend
npm run build
```

## 10. 健康检查

完成启动后至少验证：

```powershell
Invoke-RestMethod http://localhost:8000/health
Invoke-RestMethod http://localhost:8000/api/v1/categories -Headers @{ "X-School-Code" = "jiangnan" }
```

浏览器链路应覆盖登录、动态分类加载、发布、管理员审核、两类协同验证、AI 搜索正常模式与关键词降级，以及跨校切换后的数据隔离。

## 11. 数据库维护边界

- openGauss 是唯一数据库，禁止新增 SQLite 连接、依赖或测试夹具；
- Schema 变更通过 Alembic 管理，部署前检查迁移脚本；
- 删除 openGauss 容器数据卷时使用 `docker compose down -v opengauss`；
- 需要保留的数据库备份和导出文件不得混入源码目录；
- 任何测试、重置或种子脚本执行前先确认目标数据库名称和环境变量。
