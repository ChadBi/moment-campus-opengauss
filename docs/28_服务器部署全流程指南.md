## 1. 准备工作

### 1.1 你需要什么

| 项 | 要求 | 说明 |
|---|---|---|
| 云服务器 | 2核4G以上，推荐 Ubuntu 22.04 | 阿里云/腾讯云/华为云均可，系统盘≥40G |
| 域名 | 已备案的域名 | 国内服务器必须备案才能用80/443端口 |
| openGauss 镜像 | opengauss:7.0.0-RC3 轻量版 | 从官网下载 |
| SSH工具 | Xshell/FinalShell/系统自带终端 | 用于连接服务器 |

### 1.2 域名解析准备

在你的域名控制台添加一条 **A记录**：
- 主机记录：例如 `moment` 或 `www` 或 `@`
- 记录值：你的服务器公网IP
- TTL：默认（10分钟）

例如：`moment.yourdomain.com` → `123.45.67.89`

**⚠️ 重要**：DNS解析生效需要几分钟到几小时，提前配置好。

## 2. 服务器初始化

### 2.1 连接服务器

使用SSH连接到你的服务器：

```bash
ssh root@你的服务器IP
```

### 2.2 更新系统并安装基础工具

**Ubuntu/Debian：**
```bash
apt update && apt upgrade -y
apt install -y curl wget git vim unzip
```

**CentOS/Rocky：**
```bash
yum update -y
yum install -y curl wget git vim unzip
```

### 2.3 安装 Docker 和 Docker Compose

使用官方一键安装脚本：

```bash
curl -fsSL https://get.docker.com | sh
```

安装完成后，启动 Docker 并设置开机自启：

```bash
systemctl start docker
systemctl enable docker
```

**（可选但推荐）** 让非root用户也能使用Docker：
```bash
usermod -aG docker $USER
newgrp docker
```

验证安装：
```bash
docker --version
docker compose version
```

看到版本号即安装成功。

### 2.4 配置防火墙（如果启用了）

**Ubuntu UFW：**
```bash
ufw allow 22/tcp    # SSH
ufw allow 80/tcp    # HTTP
ufw allow 443/tcp   # HTTPS
ufw reload
```

**云服务商安全组：**
记得在云服务商控制台的安全组中也放行 80 和 443 端口！

## 3. 上传项目代码

### 方式一：使用 Git（推荐）

如果代码在 Git 仓库（GitHub/Gitee等）：

```bash
# 进入你想存放项目的目录，例如 /opt
cd /opt

# 克隆仓库
git clone 你的仓库地址 moment-campus
cd moment-campus
```

### 方式二：本地上传（用 FinalShell/WinSCP）

1. 在本地将整个 `moment-campus` 文件夹打包成 zip
2. 使用 FinalShell 连接服务器
3. 将 zip 文件上传到 `/opt/` 目录
4. 在服务器上解压：

```bash
cd /opt
unzip moment-campus.zip
cd moment-campus
```

## 4. 导入 openGauss 镜像

openGauss 镜像较大（约400MB+），需要手动下载并导入：

### 4.1 下载镜像

在**本地电脑**访问 openGauss 官网下载：
- 地址：https://opengauss.org/zh/download/
- 选择：7.0.0-RC3 轻量版（x86_64 或 ARM，根据你的服务器架构）
- 文件名类似：`openGauss-Lite-7.0.0-RC3-x86_64.tar.gz`

### 4.2 上传镜像到服务器

使用 FinalShell/WinSCP 将下载的 tar.gz 文件上传到服务器的 `/root/` 或 `/opt/` 目录。

### 4.3 导入镜像

在服务器上执行：

```bash
docker load -i openGauss-Lite-7.0.0-RC3-x86_64.tar.gz
```

（文件名根据你下载的实际版本调整）

验证导入成功：
```bash
docker images | grep opengauss
```

应该能看到 `opengauss   7.0.0-RC3`。

## 5. 配置环境变量

### 5.1 进入 deploy 目录

```bash
cd /opt/moment-campus/deploy
```

### 5.2 复制配置模板

```bash
cp .env.prod.example .env.prod
```

### 5.3 编辑配置文件

```bash
vim .env.prod
```

**必须修改的配置项：**

```ini
# 1. 改为你的实际域名！
DOMAIN=moment.yourdomain.com

# 2. 修改数据库密码（记住这个密码，下面两处要一致）
DB_PASSWORD=你的强密码_例如_MyDbPass123!
DB_PASSWORD_ENCODED=你的强密码_URL编码_例如_MyDbPass123%21

# 3. 生成一个强随机密钥（JWT用）
# 在服务器上执行 openssl rand -hex 32 生成
SECRET_KEY=这里填入openssl生成的随机字符串
```

**关于密码中的特殊字符URL编码：**
- `@` → `%40`
- `!` → `%21`
- `#` → `%23`
- `$` → `%24`
- `%` → `%25`
- `^` → `%5E`
- `&` → `%26`
- `*` → `%2A`

**生成SECRET_KEY：**
```bash
openssl rand -hex 32
```
把输出的64位十六进制字符串复制到 `SECRET_KEY=` 后面。

### 5.4 给脚本添加执行权限

```bash
chmod +x init.sh deploy.sh
```

## 6. 执行初始化脚本

### 6.1 运行初始化脚本

```bash
./init.sh
```

脚本会自动完成以下事情：
1. ✅ 检查 Docker 环境
2. ✅ 创建必要目录
3. ✅ 配置 Nginx（HTTP模式，用于申请证书）
4. ✅ 启动 openGauss 数据库
5. ✅ 等待数据库就绪
6. ✅ 执行数据库迁移（建表）
7. ✅ 填充江南大学演示数据
8. ✅ 询问是否申请 SSL 证书

### 6.2 关键步骤：确认域名解析

当脚本询问：
```
请确认域名 your-domain.com 已解析到本服务器IP (y/N)
```

**先在本地测试域名解析是否生效：**
打开一个新的终端（本地电脑）：
```bash
ping your-domain.com
```
或者访问：https://tool.chinaz.com/dns/ 查询你的域名A记录是否指向服务器IP。

确认解析生效后，输入 `y` 回车。

### 6.3 SSL 证书申请

脚本会自动使用 Let's Encrypt 申请免费 SSL 证书。

**申请证书的条件：**
- ✅ 域名已正确解析到服务器IP
- ✅ 服务器80端口可从公网访问
- ✅ 域名已备案（国内服务器必须）

证书申请成功后，脚本会自动切换到 HTTPS 配置并重启 Nginx。

## 8. 日常运维

### 8.1 常用命令

**进入 deploy 目录：**
```bash
cd /opt/moment-campus/deploy
```

**查看服务状态：**
```bash
docker compose -f docker-compose.prod.yml ps
```

**查看所有日志：**
```bash
docker compose -f docker-compose.prod.yml logs -f
```

**查看某个服务日志：**
```bash
docker compose -f docker-compose.prod.yml logs -f backend
docker compose -f docker-compose.prod.yml logs -f frontend
docker compose -f docker-compose.prod.yml logs -f nginx
```

**重启所有服务：**
```bash
docker compose -f docker-compose.prod.yml restart
```

**停止所有服务：**
```bash
docker compose -f docker-compose.prod.yml down
```

**停止并删除数据（⚠️ 会删除数据库！）：**
```bash
docker compose -f docker-compose.prod.yml down -v
```

### 8.2 更新部署（代码更新后）

当你有新的代码提交后：

```bash
cd /opt/moment-campus/deploy
./deploy.sh
```

脚本会自动：
1. 拉取最新 Git 代码
2. 重新构建前端和后端镜像
3. 重启服务
4. 执行数据库迁移

### 8.3 备份数据库

**手动备份：**
```bash
cd /opt/moment-campus/deploy
docker compose -f docker-compose.prod.yml exec opengauss gsql -d moment_campus -U gaussdb -W'你的数据库密码' -c "\dt"

# 导出整个数据库
docker exec moment-opengauss gs_dump -U gaussdb -W'你的数据库密码' moment_campus -F c -f /tmp/backup.dump
docker cp moment-opengauss:/tmp/backup.dump ./backup_$(date +%Y%m%d).dump
```

**建议设置定时备份：**
可以添加 crontab 定时任务自动备份。

### 8.4 查看上传的文件

用户上传的图片/文件存储在 Docker volume `backend-uploads` 中，会持久化保存。

### 8.5 重置管理员密码

如果忘记管理员密码，可以进入后端容器重置：

```bash
cd /opt/moment-campus/deploy
docker compose -f docker-compose.prod.yml exec backend python -c "
import asyncio
from app.database import AsyncSessionLocal
from app.models import User
from app.core.security import get_password_hash

async def reset():
    async with AsyncSessionLocal() as db:
        user = await db.get(User, 1)
        if user:
            user.hashed_password = get_password_hash('pass123')
            await db.commit()
            print('密码已重置为: pass123')
asyncio.run(reset())
"
```

## 9. 常见问题

### Q1: 域名访问显示 "502 Bad Gateway"

**原因：** 后端还没启动完成，或者后端启动失败。

**排查：**
```bash
docker compose -f docker-compose.prod.yml logs backend
```

查看后端日志是否有报错。常见原因：
- 数据库连接失败 → 检查 openGauss 是否正常启动
- 数据库迁移没执行 → 重新运行初始化或手动执行迁移

等待1-2分钟，后端启动完成后会自动恢复。

### Q2: SSL 证书申请失败

**原因：**
- 域名没解析到服务器
- 80端口被占用/防火墙没开
- 域名没备案（国内服务器）

**排查：**
1. 本地电脑 `ping 你的域名` 确认IP正确
2. 服务器上 `curl http://你的域名/.well-known/acme-challenge/test` 看是否能访问
3. 检查云服务商安全组是否开放80端口

**解决后重试：**
先停止容器：
```bash
docker compose -f docker-compose.prod.yml down
```
然后重新运行 `./init.sh`。

### Q3: openGauss 容器一直重启

**原因：** 数据卷损坏，或权限问题。

**解决：**
```bash
# 停止所有容器
docker compose -f docker-compose.prod.yml down

# 删除数据卷（⚠️ 会丢失数据！首次部署可执行）
docker volume ls | grep opengauss-data
docker volume rm deploy_opengauss-data  # 实际名称看docker volume ls输出

# 重新初始化
./init.sh
```

### Q4: 后端日志报 "password authentication failed"

**原因：** `.env.prod` 中的数据库密码配置错误。

**检查：**
1. `DB_PASSWORD` 和 `DB_PASSWORD_ENCODED` 必须一致（只是URL编码区别）
2. 特殊字符必须正确编码（@ → %40）
3. 如果修改过密码，确保重启容器生效

### Q5: 前端页面显示正常但 API 请求失败

**原因：**
- 后端没启动
- Nginx 反代配置有问题

**排查：**
1. 访问 `https://你的域名/health` 看是否返回ok
2. 检查前端容器Nginx配置：
```bash
docker exec moment-frontend cat /etc/nginx/conf.d/default.conf
```

### Q6: 如何更新域名/重新配置？

如果第一次配置错了需要重来：

```bash
cd /opt/moment-campus/deploy

# 停止服务
docker compose -f docker-compose.prod.yml down

# 删除旧证书（可选）
rm -rf nginx/certbot/conf/live/你的域名
rm -rf nginx/certbot/conf/archive/你的域名
rm -rf nginx/certbot/conf/renewal/你的域名.conf

# 重新编辑配置
vim .env.prod

# 重新初始化
./init.sh
```

### Q7: 服务器重启后服务会自动启动吗？

**会！** 因为所有容器都设置了 `restart: always`，服务器重启后 Docker 会自动启动所有容器。

验证：
```bash
# 重启服务器后
reboot

# 重新连接后查看
docker ps
```

### Q8: 如何在没有域名的情况下部署（纯IP访问）？

如果暂时没有域名，可以修改配置只用HTTP：

1. 编辑 `.env.prod`，`DOMAIN=你的服务器IP`
2. 运行 `./init.sh`，当问是否申请SSL证书时输入 `N`
3. 直接访问 `http://你的服务器IP`

⚠️ 但注意：国内服务器没有备案的话，80端口可能被云服务商拦截。

### Q9: 如何查看资源占用？

```bash
# 查看容器资源使用
docker stats

# 查看磁盘占用
df -h
docker system df
```

## 📁 部署文件说明

| 文件 | 作用 |
|---|---|
| `backend/Dockerfile` | 后端Python镜像构建 |

| `deploy/nginx/moment.conf.template` | Nginx生产配置模板（HTTPS） |
