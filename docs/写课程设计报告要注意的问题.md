# 写课程设计报告要注意的问题

1. 字体和格式参照发放的课程设计模板执行。

2. **图表与界面规范**
    - 报告内所有流程图、ER图、表格、系统界面截图等，表名标注在表格上方，图名标注在图片下方。
    - 每张图、每个表格下方，需配有至少1-2段文字进行解释说明。
    - 详细设计章节需放入系统全部界面，每个界面下方需配有至少1-2段文字进行详细解释。
    - 每个界面的核心代码（约十几行）附在对应界面的解释说明下方，其余完整代码统一放在报告末尾的附录代码章节。

3. **选题要求**：需从课设指导书的题目中任选一题完成，也可自拟题目。

4. **演示要求**：准备演示的同学需预先打开系统与报告，报告通过「视图」菜单设置为双页或多页显示；演示顺序为先演示系统，再查看报告。

5. **原创要求**：课程设计报告需结合自身题目独立编写，不得与其他同学内容雷同，不得从网站、书籍中成段复制抄袭，一经发现后果自负。
