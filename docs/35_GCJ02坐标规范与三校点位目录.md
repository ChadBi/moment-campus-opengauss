# GCJ-02 坐标规范与三校点位目录

## 1. 唯一坐标契约

- 数据库、后端 API、CSV 导入、MapLibre 地图边界和高德底图统一使用 **GCJ-02**。
- 浏览器 `navigator.geolocation` 返回的 WGS-84 坐标必须先转换为 GCJ-02，之后才能用于地图定位。
- 地图点击得到的坐标已经处于当前高德底图坐标空间，直接按 GCJ-02 保存。
- 接口字段名保持 `latitude` / `longitude`，不在单条响应中重复增加坐标系字段。
- 当前产品只支持中国大陆校园；中国境外坐标不执行偏移转换，但不作为正式业务契约。

## 2. 质量口径

| 质量 | 含义 |
|------|------|
| `amap_poi` | 有唯一匹配的高德地点页，坐标直接取自该 POI |
| `demo_approximate` | 泛化演示名称不存在唯一 POI，按高德底图人工校准到对应校区合理区域，不宣称为精确真实地点 |

代码侧唯一目录为 `backend/app/data/demo_coordinates.py`；本文件用于审阅和交付说明。数据库可通过 `backend/.venv/Scripts/python scripts/audit_demo_coordinates.py --strict` 做只读核对。

## 7. 迁移规则

- Alembic 只更新学校代码、地点名称和旧坐标同时匹配的演示记录。
- 已人工修正的同名地点不会被覆盖。
- 非演示地点不自动转换；审计脚本仅报告超出校区范围的记录。
- downgrade 只回退仍保持本版本新坐标的记录，避免覆盖迁移后再次人工修改的数据。
