## 1. 项目概述

**项目名称**：此刻校园（Moment Campus）  
**项目定位**：以校园地图为核心入口的校园信息共享与沉淀平台，通过地点、时间、分类、标签与有效期组织校园信息，让分散在社交群组中的校园生活信息变得可搜索、可验证、可长期沉淀。  
**演示学校**：江南大学蠡湖校区（code=`jiangnan`，中心坐标 31.4837/120.2712，zoom=16）；种子数据同时含 fudan、zju 两所学校（共3校，AGENTS.md 称「演示学校唯一」已过时）。

## 4. 系统架构

```
浏览器(React) ←→ [nginx 反代] ←→ FastAPI(uvicorn) ←→ openGauss 7.0.0-RC3
                                        ↓
                               backend/uploads/ (静态文件)
```

- 前端通过 `VITE_API_BASE_URL` 配置 API 地址；开发环境直连 `localhost:8000`，生产通过 nginx 反代同源 `/api/v1`
- JWT access token（30分钟）+ refresh token（7天），均存于 localStorage
- 三级 RBAC：`user < admin < super_admin`，统一通过 `app/core/permissions.py:require_role()` 校验
- 多租户：通过 `X-School-Code` 请求头或 `?school=` 参数区分学校数据隔离

| 角色 | 标识 | 功能范围 |
|------|------|----------|
| 游客（未登录） | — | 浏览帖子列表、搜索、地图标记、分类筛选（需传 school 参数） |

**实测权限边界**：
- 未登录访问管理接口 → `401 Unauthorized` ✓
- 普通用户访问管理接口 → `403 Forbidden` ✓
- 管理员访问平台级接口 → `403 Forbidden` ✓（super_admin only）
- 管理员访问管理接口 → `200 OK` ✓

## 20. 项目启动与使用指南

### 环境要求
- Docker Desktop（用于 openGauss 容器）
- Python 3.10+（已有 .venv/Python 3.14.3）
- Node.js 18+
- uv（推荐）或 pip

### 启动步骤
```bash
# 1. 启动数据库
docker compose up -d opengauss

# 2. 后端（Windows PowerShell）
cd backend
$env:APP_ENV = "opengauss"
$env:PYTHONIOENCODING = "utf-8"
.\.venv\Scripts\Activate.ps1
alembic upgrade head          # 首次执行迁移
python scripts/seed_data.py   # 首次填充演示数据
uvicorn app.main:app --reload

# 3. 前端
cd frontend
npm install
npm run dev
```

- `http://localhost:8000/health/live` → `{"status":"alive"}`
