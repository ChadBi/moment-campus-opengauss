# 内容与分类设计

> 此刻校园 · Moment Campus  
> 版本：1.0  
> 最后更新：2026-06-18

## 1. 概述

本文档描述"此刻校园"平台的内容分类体系、字段设计、标签体系和有效期规则。平台通过 12 个核心分类组织校园信息，每个分类具有通用字段和特有字段，支持灵活的标签系统和有效期管理。

### 2.2 分类详细设计

#### C01：校园美食

**分类描述：** 分享校园食堂窗口、餐厅、小吃的推荐信息，包括菜品、价格、营业时间等。

**特有字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| recommended_dishes | 文本 | 否 | 推荐菜品，多个用逗号分隔 |
| price_range | 枚举 | 否 | 价格区间：<10元、10-20元、20-30元、>30元 |
| business_hours | 文本 | 否 | 营业时间，如"6:30-20:00" |
| seating_capacity | 数字 | 否 | 座位数量（估计值） |
| has_delivery | 布尔 | 否 | 是否支持配送 |

**有效期特点：** 默认 90 天，美食信息相对稳定但可能因窗口调整而变化。

**交互差异：** 
- 支持"想去"快捷按钮（类似点赞）
- 显示价格标签便于快速筛选
- 推荐菜品可点击搜索相关信息

**展示重点：** 
- 突出显示推荐菜品和图片
- 价格区间用颜色标签展示
- 营业时间在显著位置显示

---

#### C02：校园动物

**分类描述：** 记录校园中的流浪猫狗、鸟类等动物信息，包括出没地点、时间、性格特点等。

**特有字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| animal_type | 枚举 | 是 | 动物类型：猫、狗、鸟、其他 |
| animal_name | 文本 | 否 | 动物昵称（如有） |
| appearance_time | 文本 | 否 | 常见出现时间段，如"早晨6-8点" |
| frequency | 枚举 | 否 | 出没频率：经常、偶尔、罕见 |
| temperament | 枚举 | 否 | 性格：亲人、胆小、凶猛、不确定 |
| is_neutered | 布尔 | 否 | 是否已绝育（如已知） |

**有效期特点：** 永久有效，但需要定期确认动物是否仍在校园。

**交互差异：** 
- 支持"想去看看"快捷按钮
- 动物照片展示优先级高
- 支持标记动物出没范围（地图绘制区域）

**展示重点：** 
- 大图展示动物照片
- 突出显示出没时间和地点
- 性格特点用图标+文字展示

---

**特有字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| service_types | 多选枚举 | 是 | 服务类型：黑白打印、彩色打印、复印、扫描、装订、证件照 |
| price_bw | 数字 | 否 | 黑白打印单价（元/张） |
| price_color | 数字 | 否 | 彩色打印单价（元/张） |
| business_hours | 文本 | 否 | 营业时间 |
| contact_phone | 文本 | 否 | 联系电话 |
| has_delivery | 布尔 | 否 | 是否支持配送 |
| delivery_fee | 数字 | 否 | 配送费（元） |

**有效期特点：** 默认 90 天，服务信息相对稳定。

**交互差异：** 
- 价格信息突出显示
- 支持一键拨号（移动端）
- 营业时间显示当前是否营业中

**展示重点：** 
- 价格信息用表格清晰展示
- 服务类型用标签展示
- 联系方式在显著位置

#### C04：拍照地点

**分类描述：** 推荐校园内适合拍照打卡的地点，包括最佳拍摄时间、场景类型、拍摄建议等。

**特有字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| scene_type | 多选枚举 | 是 | 场景类型：建筑、自然风光、室内、夜景、季节特色 |
| best_time | 文本 | 否 | 最佳拍摄时间，如"清晨"、"黄昏"、"雨后" |
| photography_tips | 文本 | 否 | 拍摄建议 |
| equipment_suggestion | 文本 | 否 | 推荐设备，如"手机即可"、"建议广角镜头" |
| accessibility | 枚举 | 否 | 可达性：容易到达、需要攀爬、限制进入 |

**有效期特点：** 永久有效，季节性地标可标注最佳季节。

**交互差异：** 
- 图片画廊模式展示
- 支持按场景类型筛选
- 可关联季节标签

**展示重点：** 
- 高质量图片展示（大图、轮播）
- 场景类型用图标展示
- 最佳拍摄时间突出显示

#### C05：学习空间

**分类描述：** 分享适合自习、学习的校园空间信息，包括环境、设施、开放时间等。

**特有字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| quiet_level | 枚举 | 是 | 安静程度：非常安静、较安静、一般、较吵 |
| has_power_outlet | 布尔 | 是 | 是否有电源插座 |
| has_wifi | 布尔 | 是 | 是否有WiFi |
| capacity | 数字 | 否 | 容纳人数（估计值） |
| opening_hours | 文本 | 否 | 开放时间 |
| seat_type | 多选枚举 | 否 | 座位类型：普通桌椅、带隔板座位、沙发、站立桌 |
| booking_required | 布尔 | 否 | 是否需要预约 |

**有效期特点：** 默认 90 天，开放时间可能因假期调整。

**交互差异：** 
- 实时显示当前是否开放
- 支持"想去学习"快捷按钮
- 安静程度用可视化图标展示

**展示重点：** 
- 安静程度和插座情况突出显示
- 开放时间清晰展示
- 环境照片优先展示

#### C06：校园活动

**分类描述：** 发布校园社团活动、讲座、比赛、演出等活动信息。

**特有字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| start_time | 日期时间 | 是 | 活动开始时间 |
| end_time | 日期时间 | 是 | 活动结束时间 |
| organizer | 文本 | 是 | 主办方/组织方 |
| registration_required | 布尔 | 否 | 是否需要报名 |
| registration_deadline | 日期时间 | 否 | 报名截止时间 |
| registration_link | URL | 否 | 报名链接 |
| contact_info | 文本 | 否 | 联系方式 |
| participant_limit | 数字 | 否 | 参与人数限制 |
| fee | 数字 | 否 | 参与费用（元） |

**有效期特点：** 自定义日期，默认为活动结束时间。活动结束后自动标记为已过期。

**交互差异：** 
- 倒计时显示（距离活动开始/结束）
- 支持"想参加"快捷按钮
- 可添加到日历
- 报名状态实时更新

**展示重点：** 
- 活动时间突出显示（大字体、颜色区分）
- 倒计时醒目展示
- 主办方信息清晰可见
- 报名按钮在显著位置

#### C07：失物招领

**分类描述：** 发布丢失物品或拾到物品的信息，帮助校园成员找回失物。

**特有字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| type | 枚举 | 是 | 类型：失物（我丢了）、招领（我捡到了） |
| item_category | 枚举 | 是 | 物品类别：证件、电子产品、书籍、衣物、钥匙、其他 |
| item_description | 文本 | 是 | 物品详细描述 |
| lost_time | 日期时间 | 否 | 丢失/拾到时间 |
| contact_method | 枚举 | 是 | 联系方式类型：私信、电话、微信、其他 |
| contact_info | 文本 | 是 | 联系方式（根据类型填写） |
| reward | 数字 | 否 | 酬金（元，仅失物类型） |

**有效期特点：** 默认 30 天，失物招领信息时效性强，过期后自动降低展示权重。

**交互差异：** 
- 类型（失物/招领）用不同颜色标签区分
- 支持"我见到了"快捷反馈
- 联系方式默认隐藏，点击显示
- 物品找到后可标记为"已找回"

**展示重点：** 
- 类型标签醒目（红色=失物，绿色=招领）
- 物品照片优先展示
- 联系方式在安全提示后显示
- 时间信息突出（丢失多久了）

#### C10：校园提醒

**分类描述：** 发布校园内的临时提醒信息，如停水停电、道路施工、安全检查等。

**特有字段：**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| reminder_type | 枚举 | 是 | 提醒类型：停水、停电、施工、安全检查、交通管制、其他 |
| impact_scope | 文本 | 是 | 影响范围（如"X号楼"、"全校区"） |
| start_time | 日期时间 | 是 | 开始时间 |
| end_time | 日期时间 | 否 | 预计结束时间 |
| severity | 枚举 | 是 | 严重程度：轻微、一般、严重 |
| source | 文本 | 否 | 信息来源（如"后勤部通知"） |

**交互差异：** 
- 严重程度用颜色区分（黄、橙、红）
- 支持"知道了"快捷确认
- 影响范围可在地图上高亮显示
- 倒计时显示剩余时间

**展示重点：** 
- 提醒类型和严重程度用图标+颜色醒目展示
- 影响范围和时间信息突出
- 倒计时在显著位置

## 4. 标签体系

### 4.1 系统预设标签

每个分类提供一组系统预设标签，用户发布时可快速选择：

| 分类 | 预设标签 |
|------|----------|
| 校园美食 | 便宜、好吃、分量足、推荐、必吃、早餐、午餐、晚餐、夜宵、辣、不辣、素食 |
| 校园动物 | 可爱、亲人、胆小、凶猛、已绝育、需要帮助、固定出没 |
| 打印服务 | 便宜、快速、质量好、彩色、双面、装订、证件照、24小时 |
| 拍照地点 | 出片、网红打卡、风景好、人少、免费、适合自拍、适合合影 |
| 学习空间 | 安静、有插座、有WiFi、人少、空调、明亮、适合小组 |
| 校园活动 | 免费、报名、讲座、比赛、演出、招新、限时、热门 |
| 失物招领 | 紧急、重要证件、电子产品、已找到、求助 |
| 便民服务 | 便宜、快速、上门、质量好、推荐、24小时 |
| 配送信息 | 快速、便宜、免配送费、支持预约、24小时 |
| 校园提醒 | 紧急、重要、临时、长期、注意 |
| 二手与闲置 | 全新、便宜、急售、免费赠送、包邮、可议价 |
| 其他信息 | 推荐、重要、紧急、求助、分享 |

### 4.2 用户自定义标签

用户可以创建自定义标签，规则如下：

- 标签长度：2-20字符
- 每条信息最多5个标签（系统+自定义总计）
- 标签不能包含特殊字符（如#、@、&等）
- 标签不能重复
- 自定义标签会被系统记录，高频使用的标签可被推荐

### 4.3 标签使用规则

1. **发布时添加标签：**
   - 优先展示系统预设标签
   - 支持搜索预设标签
   - 支持输入自定义标签
   - 已选标签可删除

2. **浏览时筛选标签：**
   - 支持按标签筛选信息
   - 支持多标签组合筛选
   - 热门标签优先展示

3. **标签管理：**
   - 管理员可添加/修改/删除系统预设标签
   - 高频自定义标签可被提升为系统标签
   - 标签使用次数统计

## 5. 有效期规则

### 5.1 有效期类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 永久 | 信息长期有效，无过期时间 | 地点信息、动物信息、拍照地点 |
| 短期-7天 | 7天后过期 | 临时提醒、紧急信息 |
| 短期-30天 | 30天后过期 | 失物招领、二手交易、一般信息 |
| 短期-90天 | 90天后过期 | 美食、服务、学习空间等 |
| 自定义日期 | 用户指定具体过期日期 | 校园活动等有时限的信息 |

### 5.2 各分类默认有效期建议

| 分类 | 默认有效期 | 说明 |
|------|------------|------|
| 校园美食 | 90天 | 美食信息相对稳定，但可能因窗口调整变化 |
| 校园动物 | 永久 | 动物信息长期有效，需定期确认 |
| 打印服务 | 90天 | 服务信息相对稳定 |
| 拍照地点 | 永久 | 地点信息长期有效 |
| 学习空间 | 90天 | 空间信息相对稳定，假期可能调整 |
| 校园活动 | 自定义 | 默认为活动结束时间 |
| 失物招领 | 30天 | 时效性强，过期后降低权重 |
| 便民服务 | 90天 | 服务信息相对稳定 |
| 配送信息 | 90天 | 配送服务可能调整 |
| 校园提醒 | 7天 | 时效性极强 |
| 二手与闲置 | 30天 | 交易信息时效性强 |
| 其他信息 | 30天 | 一般信息默认30天 |

### 5.3 过期处理规则

**过期前提醒：**

- 过期前7天：通知发布者"您的信息即将过期，是否延长有效期？"
- 过期前1天：再次提醒发布者

**过期后处理：**

1. **状态变更：** 信息状态从"有效"变为"可能过期"
2. **展示调整：** 
   - 信息仍可在详情页查看
   - 在列表中的展示权重降低
   - 显示"可能过期"黄色标识
3. **用户确认：** 
   - 其他用户可确认"仍然有效"或"已经失效"
   - 如3人以上确认"仍然有效"，状态恢复为"有效"
   - 如3人以上确认"已经失效"，状态变为"已过期"
4. **管理员处理：** 
   - 管理员可查看可能过期的信息列表
   - 管理员可手动延长有效期、标记过期或隐藏信息

**已过期信息处理：**

- 显示"已过期"红色标识
- 在搜索结果中排名靠后
- 不在首页信息流中展示
- 保留90天后自动隐藏（可配置）

## 6. 分类与类型的区别

### 6.1 概念说明

**分类（Category）** 和 **信息类型（PostType）** 是两个不同的概念：

| 维度 | 分类（Category） | 信息类型（PostType） |
|------|------------------|----------------------|
| **定义** | 信息的内容主题划分 | 信息的发布形式划分 |
| **作用** | 组织信息内容，便于用户按主题浏览 | 控制信息的展示形式和交互方式 |
| **数量** | 12个固定分类 | 可扩展的类型系统 |
| **变更频率** | 相对稳定，很少新增 | 可根据需求灵活扩展 |
| **用户感知** | 用户可见，用于筛选和浏览 | 部分可见，主要影响展示形式 |

### 6.2 信息类型（PostType）设计

信息类型用于控制信息的展示形式和交互方式：

| 类型 | 说明 | 展示特点 |
|------|------|----------|
| 普通信息 | 标准的信息卡片 | 标准卡片展示 |
| 置顶信息 | 管理员置顶的重要信息 | 顶部置顶展示，带"置顶"标识 |
| 精选信息 | 高质量信息被标记为精选 | 带"精选"标识，权重提升 |
| 活动信息 | 有时间起止的信息 | 显示倒计时，可添加到日历 |
| 紧急信息 | 需要快速传播的信息 | 特殊颜色标识，优先展示 |
| 聚合信息 | 同一地点/主题的多个信息聚合 | 显示信息数量，可展开查看 |

### 6.3 分类与类型的关系

- 一条信息属于**一个分类**（如"校园美食"）
- 一条信息可以有**一个类型**（如"精选信息"）
- 分类和类型是正交的：任何分类的信息都可以有不同的类型
- 例如：一条"校园美食"信息可以同时是"精选信息"

### 6.4 使用场景

**分类的使用场景：**
- 用户按主题浏览信息
- 发布时选择信息主题
- 搜索时按分类筛选
- 统计各分类信息数量

**类型的使用场景：**
- 控制信息展示形式
- 管理员标记特殊信息
- 影响信息排序权重
- 触发特殊交互（如活动倒计时）
