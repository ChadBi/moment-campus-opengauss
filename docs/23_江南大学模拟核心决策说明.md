## 1. 决策内容

### 1.1 决策声明

**后续开发中，"此刻校园"项目以江南大学为模拟核心进行制作。**

具体含义：
- 学校数据以**江南大学**为唯一/核心模拟对象
- 校园地点、坐标、地图中心点等以**江南大学蠡湖校区**为准
- 演示用户、信息、评论等业务数据围绕江南大学的校园生活展开
- 后续若涉及多学校支持，江南大学作为第一所且默认学校

### 1.2 决策依据

- 用户明确指示（2026-06-29）
- 江南大学是教育部直属、"211工程"、"双一流"学科建设高校，符合项目"大学校园信息共享"的定位
- 蠡湖校区占地 3200 亩、水域 400 亩，校园规模适中，地点类型丰富（食堂、图书馆、体育馆、教学楼、宿舍、湖泊等），适合演示项目全部功能

## 3. 与 Base 项目的差异分析

### 3.1 Base 项目当前学校数据【已确认】

依据 [backend/scripts/seed_data.py](file:///d:/Project/database-class/moment-campus/backend/scripts/seed_data.py) 第 38–66 行：

```python
schools = [
    School(
        name="华东师范大学",
        code="ecnu",
        province="上海",
        city="上海",
        address="上海市普陀区中山北路3663号",
        center_lat=31.2297,
        center_lng=121.4075,
        map_zoom=15,
        is_active=True
    ),
    School(
        name="复旦大学",
        code="fudan",
        province="上海",
        city="上海",
        address="上海市杨浦区邯郸路220号",
        center_lat=31.2982,
        center_lng=121.5035,
        map_zoom=15,
        is_active=True
    )
]
```

Base 项目共存入 2 所上海高校，地点数据也围绕这两所学校展开（共 15 个地点）。

### 3.2 目标改造方案

| 项 | Base 项目现状 | 目标状态 | 改造方式 |
| -- | ------------- | -------- | -------- |
| 学校数量 | 2 所（华东师大、复旦） | **1 所**（江南大学） | seed_data.py 改为仅保留江南大学 |
| 学校主键 | schools[0]=华东师大, schools[1]=复旦 | schools[0]=江南大学 | 重新生成 |
| 地点数据 | 围绕华东师大（8 个）+ 复旦（7 个） | 围绕江南大学蠡湖校区（建议 10–15 个） | 重写地点列表 |
| 坐标中心 | 上海（31.22, 121.40） | 无锡（31.48, 120.27） | 修改 School.center_lat/center_lng |
| 用户关联 | schools[i % 2].id（两校交替） | 全部关联 schools[0].id | 修改用户分配逻辑 |
| 信息关联 | 两校交替 | 全部属于江南大学 | 修改信息分配逻辑 |
| 专题集合 | 两校分布 | 全部属于江南大学 | 修改专题集合分配 |
| 地图中心 | 上海 | 无锡蠡湖校区 | 前端 MapPage 默认中心点调整 |
