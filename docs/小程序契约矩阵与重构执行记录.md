# 微信小程序契约矩阵与重构执行记录

> 2026-08-07。本文是小程序对齐 Web/后端的实施依据；历史报告中的旧接口只作为历史事实保留，不再作为有效调用契约。

小程序环境地址由 `miniprogram/config/env.ts` 按微信运行版本自动选择：开发者工具使用本地 `http://localhost:8000`，体验版使用 `https://campus.chaina1.com`，正式版使用线上生产地址；必要时可通过构建标记 `__ENV__` 显式覆盖。线上详情路由部署完成前，不上传体验版进行地点详情验收。

## 1. 租户与学校

| 能力 | 当前接口 | 小程序 service | 关键字段/规则 |
| --- | --- | --- | --- |
| 学校目录 | `GET /schools` | `services/schools.ts:listSchools` | 响应为数组；`center_lat/center_lng/map_zoom` |
| 当前学校 | `GET /schools/current` | `getCurrentSchool` | 通过 `X-School-Code` 解析租户 |
| 学校切换 | `POST /schools/{code}/join` | `joinSchool` | 普通用户一对一绑定；成功后再拉当前学校 |
| 我的成员关系 | `GET /me/memberships` | `listMemberships` | 仅在“我的”页展示当前学校，不提供默认校操作 |

所有非认证请求由 `services/request.ts` 注入 `X-School-Code`。切校流程先使用目标 code 发起 join 和 current 请求，详情成功后才原子更新 `campusStore`，并清理旧学校作用域缓存。

## 2. 帖子与互动

| 能力 | 当前接口 | 归一化结果 |
| --- | --- | --- |
| 列表/详情 | `GET /posts`、`GET /posts/{id}` | `Post`：`images[{image_url,thumbnail_url}]`、`like_count/comment_count/view_count`、`expire_at`、嵌套 `author/category/location` |
| 发布/编辑 | `POST /posts`、`PUT /posts/{id}` | `images` 对象数组；地点使用 `location_id` 或 `location_name + location_lat + location_lng` |
| 点赞 | `POST /posts/{id}/like` | 只读取 `is_liked`、`like_count` |
| 评论 | `GET/POST /posts/{id}/comments` | 支持 `parent_id`、`reply_to_user_id`、`replies` |
| 协同验证 | `POST /posts/{id}/validate`、`GET /posts/{id}/validation-stats` | 使用 confirmation/refutation 与后端统计 |

页面不再直接兼容多套旧字段，所有数组、图片、分页响应在 service/normalize 层完成转换。

## 3. 地点与摘要

- 地图只请求 `GET /locations`，中心只取当前学校的 `center_lat/center_lng/map_zoom`，不读取 GPS、不计算距离。
- 地点详情 `GET /locations/{id}`、摘要 `GET /locations/{id}/summary`、评价和资料提议接口与 Web 顺序一致：稳定资料 → 已审核 AI 摘要 → 来源/冲突 → 评价 → 资料提议。
- 发布和编辑通过地点列表静态选择地点，不调用 `wx.chooseLocation`，`app.json` 不申请 `chooseLocation` 私有权限。

## 4. 外围能力

- 搜索统一消费 `items/has_more/match_reasons/scores/fallback`，没有 `nearest`、距离或位置排序。
- 通知使用 `target_type/target_id`，全部已读为 `PUT /notifications/read-all`，未读数为 `unread_count`；不提供删除通知。
- 订阅使用 `target_type=category|location|topic`，新增统一 `services/subscriptions.ts`。
- 专题统一 `cover_url`、标准帖子计数和分页结构。

## 5. 废弃入口清单

小程序有效代码中已移除：`/me/school`、`/me/school/switch`、`/me/schools`、`/posts/{id}/interactions`、`/map/markers`、`/map/center`、`/notifications/mark-all-read`、`subscription_type`、旧帖子计数字段、`wx.chooseLocation` 和定位权限配置。微信类型声明中保留的 API 文档不属于业务调用入口。
