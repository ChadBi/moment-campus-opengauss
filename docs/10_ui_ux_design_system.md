# UI/UX 设计规范

> 此刻校园 · Moment Campus  
> 版本：2.0（地图优先优化版）  
> 最后更新：2026-06-18

## 1. 品牌关键词

### 1.1 关键词定义

| 关键词 | 设计体现 |
|--------|----------|
| **清新** | 以校园绿（#2F7D5A）为主色，搭配暖灰背景（#F7F8F5）；留白充足，元素间距宽松；避免高饱和度色彩堆叠；图标采用线性风格，不使用厚重填充 |
| **温暖** | 暖黄色（#F2B85B）用于提醒和强调场景；背景色带暖灰调（#F7F8F5）而非冷灰或纯白；文案语气亲切自然，避免生硬的系统提示语；插画和图标选择圆润友好的造型 |
| **校园感** | 图标选择贴近校园场景（书本、咖啡杯、地图、相机、猫咪等）；图片风格真实自然，不使用过度滤镜；标签颜色活泼但不刺眼；空状态插画使用校园场景题材 |
| **手绘感** | 采用不完全规则的圆角边框；纸张、便签或校园手账质感；柔和的浅绿色、浅蓝色、米白色和暖黄色；手绘风地图标记；轻量级阴影；适量涂鸦装饰；自然、有呼吸感的页面留白 |
| **轻松** | 避免过度科技感和传统后台管理系统风格；避免大量冰冷的纯白卡片和标准化组件堆叠；避免过度花哨，保证主要功能清晰易用；地图是视觉焦点，其他装饰元素服务于地图 |

### 1.2 设计避免清单

- ❌ 企业管理后台感：避免密集表格、复杂筛选器堆叠、深色顶栏
- ❌ 过度科技化：避免大面积深色背景、霓虹色、发光效果、数据可视化风格
- ❌ 大面积渐变：避免彩虹色背景、复杂渐变按钮
- ❌ 大量发光效果：避免按钮发光边框、卡片发光描边
- ❌ 密集玻璃拟态：避免所有元素都使用毛玻璃效果，仅在浮层（如顶部导航）中克制使用
- ❌ 所有内容都放在圆角卡片中：列表项、文本信息等可直接排列，合理使用卡片
- ❌ 地图被遮挡或削弱：地图是核心交互区域，装饰元素不能遮挡或削弱地图

### 1.3 设计原则

- **地图优先**：地图是核心交互区域，占据主要视觉空间，其他元素服务于地图
- **信息优先**：内容是第一公民，UI 框架应退居幕后
- **触手可及**：核心操作（如发布、搜索）应在拇指热区或视觉中心
- **即时反馈**：任何操作都应有明确的视觉或触觉反馈
- **渐进展示**：不一次性展示所有信息，按需展开
- **手绘点缀**：手绘元素作为视觉表现方式，不影响功能使用

## 2. 颜色系统

### 2.1 品牌色与背景色

| 变量名 | 色值 | 用途 |
| :--- | :--- | :--- |
| `--primary` | `#2F7D5A` | 品牌主色（校园绿）。用于主要按钮、链接、选中状态、成功标识、地图默认标记 |
| `--primary-light` | `#E8F3ED` | 主色浅色。用于标签底色、选中行背景、悬停状态背景、主色按钮的浅色变体 |
| `--bg-body` | `#F7F8F5` | 全局页面背景。带暖灰调，避免纯白刺眼 |
| `--bg-surface` | `#FFFFFF` | 内容卡片、弹窗、输入框、浮层背景 |

### 2.2 文本色

| 变量名 | 色值 | 用途 |
| :--- | :--- | :--- |
| `--text-main` | `#17211C` | 标题、正文主要内容、重要信息 |

| `--text-disabled` | `#A8B0AC` | 禁用状态文字、输入框占位符 |

| 变量名 | 色值 | 用途 |
| :--- | :--- | :--- |

### 2.5 颜色使用规则

#### 2.5.1 比例原则（60-30-10）

- **60% 背景色**：页面背景 #F7F8F5 和内容白色 #FFFFFF
- **30% 辅助色**：文本色、边框色、次文字色
- **10% 品牌色**：主色 #2F7D5A 仅用于关键操作和状态标识

#### 2.5.2 主色使用规则

- **主要按钮**：背景 #2F7D5A，白色文字
- **次要按钮**：背景 #E8F3ED，文字 #2F7D5A
- **文字按钮/链接**：文字 #2F7D5A，无背景
- **选中状态**：背景 #E8F3ED 或边框 #2F7D5A
- **成功标识**：使用 #2F7D5A

#### 2.5.3 功能色使用规则

- **暖黄色 #F2B85B**：仅用于提醒和警告场景，不用于主要操作按钮
- **失效红色 #D76565**：仅用于错误状态、删除操作、已过期标识
- **信息蓝色 #5C83B5**：用于中性信息提示、帮助说明、不确定状态

#### 2.5.4 禁止事项

- 禁止将功能色混用（如用红色表示成功）
- 禁止在同一个按钮上使用超过两种语义色
- 禁止使用未定义的颜色值（需先纳入设计 Token）

### 2.6 深色模式规划（待确认）

| 变量名 | 浅色值 | 深色值（规划） |
| :--- | :--- | :--- |
| `--bg-body` | `#F7F8F5` | `#1A1F1C` |
| `--bg-surface` | `#FFFFFF` | `#252B28` |
| `--text-main` | `#17211C` | `#E8EBE9` |

深色模式注意事项：
- 背景使用深灰而非纯黑，减少 OLED 屏幕上的拖影
- 主色略微提亮，保证在深色背景上的可辨识度
- 阴影在深色模式下改为使用更深的背景色叠加，而非黑色半透明阴影
- 图片在深色模式下可降低 5% 亮度，避免过亮刺眼

## 3. 字体层级

### 3.1 字体选择

优先使用系统默认字体栈，确保加载速度和原生体验，无需加载外部字体文件。

**正文/标题字体栈：**

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
             "Helvetica Neue", Arial, "Noto Sans SC", "PingFang SC",
             "Microsoft YaHei", sans-serif;
```

**等宽字体（用于数据展示、代码）：**

```css
font-family: "SF Mono", Monaco, "Cascadia Code", "Roboto Mono",
             Consolas, "Courier New", monospace;
```

### 3.2 标题层级

| 级别 | 移动端字号 | 桌面端字号 | 行高 | 字重 | 使用场景 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| H1 | 24px | 28px | 1.3 | 600 | 页面主标题 |
| H2 | 20px | 24px | 1.35 | 600 | 区块标题、卡片组标题 |
| H3 | 18px | 20px | 1.4 | 600 | 卡片标题、子区块标题 |
| H4 | 16px | 18px | 1.45 | 600 | 小标题、列表标题 |
| H5 | 14px | 16px | 1.5 | 600 | 辅助标题、表单标签 |
| H6 | 12px | 14px | 1.5 | 600 | 最小标题、标签文字、角标 |

### 3.3 正文字体

| 类型 | 字号 | 行高 | 字重 | 使用场景 |
| :--- | :--- | :--- | :--- | :--- |
| 正文（大） | 16px | 1.6 | 400 | 信息详情正文、长段落阅读 |
| 正文（标准） | 14px | 1.6 | 400 | 列表项描述、卡片摘要、表单输入文字 |
| 正文（小） | 12px | 1.5 | 400 | 辅助说明、时间戳、标签文字、距离信息 |
| 正文（超小） | 10px | 1.4 | 400 | 仅用于角标数字、极小辅助信息（谨慎使用） |

### 3.4 数据字体

- **数字展示**：使用等宽字体或系统默认数字，保证对齐
- **价格/统计数字**：字重 500-600，字号与上下文一致
- **时间戳**：使用次文字颜色 #66736C，字号 12px
- **距离信息**：使用次文字颜色 #66736C，字号 12px，单位用灰色

### 3.5 移动端与桌面端差异

- **移动端（< 768px）**：标题使用较小字号，节省纵向空间；正文基础字号 16px；行高略大（+0.05）提升小屏可读性
- **桌面端（>= 768px）**：标题使用较大字号，增强视觉层次；正文基础字号 16px 不变；行高标准值
- **切换方式**：通过 CSS 媒体查询在 768px 断点切换

## 4. 间距系统

### 4.1 基础间距单位

- **基础单位**：4px
- **所有间距值必须是 4 的倍数**：4、8、12、16、20、24、28、32、36、40、44、48...

### 4.2 间距层级

| 层级 | 数值 | 使用场景 |
| :--- | :--- | :--- |
| `xs` | 4px | 图标与文字间距、标签内间距、紧凑元素间空隙 |
| `sm` | 8px | 按钮内间距、标签与元素间距、小组件间距 |
| `md` | 12px | 卡片内间距、表单元素间距、列表项间距 |
| `lg` | 16px | 区块内间距、页面边距（移动端）、列表项间距（宽松） |
| `xl` | 24px | 区块之间间距、页面边距（桌面端）、表单组间距 |
| `2xl` | 32px | 页面大区块分隔、主要区块间距 |
| `3xl` | 48px | 页面顶部/底部大留白、核心区块分隔（谨慎使用） |

### 4.3 使用规则

#### 4.3.1 内间距（Padding）

| 元素 | 内间距 |
| :--- | :--- |
| 按钮（sm） | 8px 16px |
| 按钮（md） | 12px 20px |
| 按钮（lg） | 16px 24px |
| 卡片 | 12px 或 16px |
| 输入框 | 8px 12px |
| 标签 | 4px 8px |
| 页面边距（移动端） | 16px |
| 页面边距（桌面端） | 24px |

#### 4.3.2 外间距（Margin/Gap）

| 场景 | 间距 |
| :--- | :--- |
| 标题与下方正文 | 8px |
| 列表项之间 | 12px 或 16px |
| 卡片之间 | 12px 或 16px |
| 区块之间 | 24px 或 32px |
| 表单元素之间 | 12px 或 16px |
| 按钮之间 | 12px |

#### 4.3.3 一致性原则

- 相同类型的元素使用相同的间距
- 视觉层次越紧密，间距越小；越独立，间距越大
- 避免使用奇数值（如 5px、7px）
- 间距值只使用上表中定义的层级值

## 5. 圆角系统

### 5.1 圆角层级

| 层级 | 数值 | 使用场景 |
| :--- | :--- | :--- |
| `sm` | 4px | 小按钮、标签、输入框、小组件、下拉菜单 |
| `md` | 8px | 卡片、弹窗、中等按钮、图片、下拉菜单 |
| `lg` | 12px | 大卡片、底部弹窗、大型模态框 |
| `xl` | 16px | 特殊装饰元素、大型特色卡片 |
| `full` | 9999px | 圆形头像、胶囊按钮、圆形图标背景、徽章 |

### 5.2 使用规则

- **按钮**：sm 按钮用 4px，md/lg 按钮用 8px，胶囊按钮用 full
- **卡片**：普通信息卡片用 8px，特色/大卡片可用 12px
- **输入框**：统一使用 4px 或 8px
- **图片**：封面图用 8px，头像用 full（圆形）
- **弹窗/模态框**：8px 或 12px
- **标签/徽章**：4px
- **一致性**：同一类型的元素必须使用相同的圆角值

## 6. 阴影系统

### 6.1 阴影层级

| 层级 | CSS 值 | 使用场景 |
| :--- | :--- | :--- |
| `sm` | `0 1px 2px 0 rgba(0,0,0,0.05)` | 输入框、静态卡片、标签 |
| `md` | `0 4px 6px -1px rgba(0,0,0,0.1), 0 2px 4px -1px rgba(0,0,0,0.06)` | 卡片、下拉菜单、悬浮工具栏 |
| `lg` | `0 10px 15px -3px rgba(0,0,0,0.1), 0 4px 6px -2px rgba(0,0,0,0.05)` | 弹窗、悬浮卡片、固定导航栏 |
| `xl` | `0 20px 25px -5px rgba(0,0,0,0.1), 0 10px 10px -5px rgba(0,0,0,0.04)` | 模态框、全屏遮罩上的核心内容 |

### 6.2 使用规则

- **阴影方向**：统一向下，模拟自然光照
- **阴影颜色**：使用黑色透明度，不使用彩色阴影
- **层级对应**：元素层级越高（离页面越远），阴影越大
- **过渡动画**：悬停阴影变化使用 200ms ease 过渡
- **避免叠加**：不在同一元素上使用多层阴影

#### 具体场景分配

| 元素 | 默认阴影 | 悬停阴影 |
| :--- | :--- | :--- |
| 输入框 | 无 | 无（通过边框色变化反馈） |
| 静态卡片 | sm | md |
| 可交互卡片 | sm | lg |
| 按钮 | 无 | sm（可选） |
| 下拉菜单 | md | — |
| 弹窗/模态框 | lg 或 xl | — |
| 固定导航 | lg | — |

## 7. 图标规范

### 7.1 图标库

- **使用 Lucide React**：风格简洁现代、线条均匀、支持 Tree Shaking、与 React 深度集成
- **线条粗细**：统一使用 `strokeWidth={2}`（Lucide 默认值）
- **填充**：默认不填充（outline 风格），特殊状态（如已点赞、已收藏）可使用 filled 变体

### 7.2 图标尺寸规范

| 尺寸 | 数值 | 使用场景 |
| :--- | :--- | :--- |
| xs | 12px | 极小图标，用于角标、极小按钮内 |
| sm | 16px | 小图标，用于标签内、辅助说明、正文内链接图标 |
| md | 20px | 中等图标，按钮内图标、导航项图标（默认尺寸） |
| lg | 24px | 大图标，底部 Tab 图标、页面标题图标、空状态图标 |
| xl | 32px | 特大图标，空状态大图标、引导页图标 |
| 2xl | 48px | 超大图标，仅用于空状态中心大图（谨慎使用） |

### 7.3 图标使用规则

- **图标与文字组合**：图标与文字间距 4px（xs）
- **图标颜色**：默认继承当前文字颜色
- **可点击图标**：悬停时颜色变为 #2F7D5A
- **禁用图标**：颜色变为 #A8B0AC
- **图标按钮**：必须有 `aria-label` 属性，触摸区域不小于 44x44px
- **一致性**：同一界面中相同功能的图标使用相同尺寸

## 8. 按钮规范

### 8.1 按钮类型

| 类型 | 背景色 | 文字色 | 边框 | 使用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary** | `#2F7D5A` | `#FFFFFF` | 无 | 页面主操作：发布、保存、提交、确认 |
| **Secondary** | `#E8F3ED` | `#2F7D5A` | 无 | 次要操作：筛选、更多、取消 |
| **Text/Ghost** | 透明 | `#2F7D5A` | 无 | 低优先级操作：查看更多、展开、链接式操作 |
| **Danger** | `#D76565` | `#FFFFFF` | 无 | 危险操作：删除、移除、不可逆操作 |
| **Disabled** | `#E8EBE9` | `#A8B0AC` | 无 | 不可操作状态 |

### 8.2 按钮尺寸

| 尺寸 | 高度 | 内间距 | 字号 | 图标尺寸 | 使用场景 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| sm | 32px | 8px 16px | 14px | 14px | 表格行操作、紧凑布局、卡片内操作 |
| md | 40px | 12px 20px | 14px | 16px | 表单提交、一般操作（默认尺寸） |
| lg | 48px | 16px 24px | 16px | 20px | 页面主操作、移动端按钮 |

### 8.3 按钮状态

| 状态 | 样式变化 | 说明 |
| :--- | :--- | :--- |
| 默认 | 基础样式 | 正常展示 |
| 悬停（Hover） | 背景色亮度提升 5% | 鼠标悬停反馈，过渡 150ms |
| 按下（Active） | 背景色亮度降低 5% | 鼠标按下反馈 |
| 禁用（Disabled） | 透明度 50%，cursor: not-allowed | 不可操作 |
| 加载（Loading） | 显示 Spinner 图标，文字变为"处理中..." | 异步操作进行中，按钮不可重复点击 |

### 8.4 按钮使用规则

- 每个页面/区块只有一个 Primary 按钮
- Primary 按钮放在右侧或底部
- 危险操作使用 Danger 按钮，且需二次确认
- 按钮文字使用动词开头（发布、保存、取消、删除）
- 移动端 Primary 按钮可占满宽度
- 移动端按钮最小高度 44px

## 9. 表单规范

### 9.1 输入框样式

#### 9.1.1 单行输入框（Input）

- **高度**：40px（md）或 48px（lg，移动端推荐）
- **内间距**：8px 12px
- **背景色**：#FFFFFF
- **边框**：1px solid #DDE5E0
- **圆角**：4px
- **字号**：14px
- **占位符颜色**：#A8B0AC

| 状态 | 边框颜色 | 附加效果 |

- **按钮最小高度**：44px（移动端）
- **导航项最小高度**：44px
- **列表项最小高度**：44px
- **图标按钮最小尺寸**：44px × 44px
- **相邻可点击元素间距**：至少 8px

### 19.3 手势交互

| 手势 | 功能 | 反馈 |
| :--- | :--- | :--- |
| 点击（Tap） | 激活元素 | 轻微缩放 scale(0.98)，100ms |
| 长按（Long Press） | 显示上下文菜单 | 震动反馈 + 菜单弹出 |
| 左右滑动（Swipe） | 图片画廊切换 | 跟随手指移动 |
| 下拉（Pull Down） | 刷新列表 | 显示刷新图标和进度指示 |
| 上拉（Pull Up） | 加载更多 | 底部显示加载指示 |
| 左滑（Swipe Left） | 列表项操作（删除等） | 露出操作按钮 |

### 19.4 移动端布局规则

- **页面边距**：16px
- **卡片间距**：12px 或 16px
- **按钮宽度**：Primary 按钮占满宽度
- **输入框高度**：48px（lg）
- **底部导航**：固定底部，高度 56px + 安全区
- **顶部导航**：固定顶部，高度 56px

## 20. 桌面端适配

### 20.1 布局方式

- **侧边导航 + 内容区**：侧边导航固定左侧，内容区右侧滚动
- **或顶部导航 + 内容区**：顶部导航固定，内容区下方

### 20.2 最大宽度

- **内容区最大宽度**：1200px
- **文本最大宽度**：65ch（约 65 个中文字符，提升长文本可读性）
- **内容区居中**：当屏幕宽度超过 1200px + 侧边栏宽度时，内容区居中

### 20.3 响应式断点

#### 侧边导航

| 宽度 | 行为 |
| :--- | :--- |
| < 768px | 隐藏侧边导航，使用底部导航 |
| 768px - 991px | 侧边导航收起，宽度 64px，仅显示图标 |
| >= 992px | 侧边导航展开，宽度 240px |

#### 内容区卡片网格

| 宽度 | 列数 |
| :--- | :--- |
| < 768px | 1 列（单列布局） |
| 768px - 991px | 2 列 |
| 992px - 1199px | 3 列 |
| >= 1200px | 4 列 |

### 20.4 桌面端布局规则

- **页面边距**：24px
- **卡片间距**：16px 或 24px
- **按钮宽度**：自适应内容宽度
- **输入框高度**：40px（md）
- **顶部导航**：固定顶部，高度 64px
- **悬停效果**：充分利用 Hover 状态展示更多信息或视觉反馈

## 21. 无障碍设计

### 21.1 颜色对比度

- **正文文字与背景**：对比度至少 4.5:1（符合 WCAG 2.1 AA 标准）
- **大文字（>= 18px 或字重 >= 600 的 14px）**：对比度至少 3:1
- **UI 组件（按钮、输入框、图标）**：与相邻颜色对比度至少 3:1

#### 当前配色对比度验证

| 组合 | 对比度 | 是否达标 |
| :--- | :--- | :--- |
| #17211C / #FFFFFF | 16.5:1 | ✅ AA |
| #66736C / #FFFFFF | 5.5:1 | ✅ AA |
| #2F7D5A / #FFFFFF | 5.2:1 | ✅ AA |
| #D76565 / #FFFFFF | 4.6:1 | ✅ AA |
| #5C83B5 / #FFFFFF | 4.0:1 | ⚠️ 仅大文字达标 |

> 注意：信息蓝色 #5C83B5 用于小字时需验证对比度，建议仅用于大文字或搭配白色背景使用。

### 21.2 键盘导航

- **所有交互元素可聚焦**：按钮、链接、输入框、选择器、卡片等
- **焦点顺序**：按照视觉顺序从上到下、从左到右
- **焦点样式**：2px solid #2F7D5A 外发光环，偏移 2px
- **Tab 键**：前进到下一个可聚焦元素
- **Shift + Tab**：后退到上一个可聚焦元素
- **Enter / Space**：激活当前聚焦的按钮
- **Escape**：关闭弹窗、下拉菜单、模态框

### 21.3 屏幕阅读器支持

- **语义化 HTML**：使用 `<button>`、`<a>`、`<input>`、`<nav>`、`<main>` 等语义标签
- **ARIA 标签**：图标按钮必须包含 `aria-label`
- **ARIA 角色**：复杂组件添加适当的 `role` 属性
- **隐藏装饰元素**：装饰性图标使用 `aria-hidden="true"`
- **实时区域**：动态内容更新使用 `aria-live="polite"` 通知屏幕阅读器
- **图片替代文本**：有意义的图片添加描述性 `alt` 属性

### 21.4 焦点管理

- **焦点样式可见**：焦点环不被其他元素遮挡
- **模态框焦点陷阱**：模态框打开时焦点限制在模态框内循环
- **模态框关闭恢复**：关闭后焦点恢复到触发元素
- **跳转链接（Skip Link）**：页面顶部提供"跳转到主内容"的隐藏链接

### 21.5 动效与减少运动

- **支持 prefers-reduced-motion**：用户系统设置减少动画时，禁用所有非必要动画
- **动画时长**：过渡动画不超过 300ms
- **避免闪烁**：不使用频率超过 3Hz 的闪烁效果

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```
