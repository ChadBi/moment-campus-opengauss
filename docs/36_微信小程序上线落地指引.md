# 微信小程序上线落地指引（Workflow C）

> 关联任务：`tasks.md` 工作流 C（C-01 / C-02 / C-03）
> 目标：把「此刻校园」小程序从本地开发版推进到可在真机体验、进而发布的可用状态。

## 1. 现状与目标

- 小程序代码位于 `miniprogram/`，Web/后端主工程已可提供完整 API。
- **C-01 已完成**：`miniprogram/services/request.ts` 的 API Base URL 已指向公网
  `https://campus.chaina1.com/api/v1`，图片地址 `resolveImageUrl` 同步指向公网域名。
- 本指引说明把小程序上线所需的配置、隐私合规、体验版发布与体验成员加入步骤。

## 2. 合法域名配置（必须）

小程序正式环境只允许请求**已配置的合法域名**（HTTPS）。登录 [微信公众平台](https://mp.weixin.qq.com) →
目标小程序 → 「开发」→「开发管理」→「开发设置」→「服务器域名」：

| 分类 | 需配置域名 |
| --- | --- |
| request 合法域名 | `https://campus.chaina1.com` |
| uploadFile 合法域名 | `https://campus.chaina1.com`（若在小程序内上传图片） |
| downloadFile 合法域名 | `https://campus.chaina1.com`（若下载图片/文件） |
| socket 合法域名 | 暂不使用，可留空 |

> 注意：
> - 域名必须是备案过的合法域名，且通过 HTTPS 访问（`campus.chaina1.com` 已配置 Let's Encrypt 证书）。
> - 本地开发时可在微信开发者工具「详情 → 本地设置」勾选「不校验合法域名…」，便于联调；**发布前必须改为正式校验**。

## 3. 隐私保护指引（必须）

微信要求小程序涉及用户隐私（含位置、相册、摄像头、手机号等）时，需在后台填写《用户隐私保护指引》：

1. 公众平台 → 目标小程序 → 「设置」→「服务内容声明」→「用户隐私保护指引」。
2. 本小程序用到的能力：
   - **静态地点选择**：发布帖子时从当前学校的静态地图或已有地点列表中选择地点；不申请 `scope.userLocation`，不调用 `getLocation`/`chooseLocation`，不展示实时位置或距离。
   - **相册/摄像头**（`chooseImage` 发布图文）：发布帖子时选择图片。说明用途为「用于发布校园帖子时上传图片」。
3. 保存并提交审核；未完善隐私指引时部分接口会被拦截。

## 4. 用户协议与隐私政策文案

为满足合规与同学信任，建议在「关于/设置」页放置并链接以下内容（可复用平台运营文案）：

- **用户协议**：注册登录、内容发布规范（禁止虚假/骚扰/侵权信息）、6 态状态机下内容可见性、举报与协同证伪机制、账号与认证说明。
- **隐私政策**：收集信息的范围（账号、登录教育邮箱认证、用户主动选择的地点、图片）、用途、存储、第三方共享（如有）、用户权利（查询/更正/删除/注销）、联系方式。

> 说明：校园身份认证使用登录教育邮箱发送验证码/认证链接，不要求填写学号或第二邮箱。

## 5. 体验版发布与体验成员（C-03）

体验版供指定同学在真机提前体验，无需走完整发布审核：

1. 使用微信开发者工具打开 `miniprogram/` 工程，确认 `project.config.json` 的 AppID 正确。
2. 编译通过后，点击「上传」，填写版本号与项目备注，上传到后台成为「开发版」。
3. 公众平台 → 「版本管理」→「开发版本」→ 找到刚上传的版本，点「选为体验版」。
4. 添加体验成员：微信公众平台 → 「成员管理」→「体验成员」→ 添加同学微信号（上限数量内）。
5. 体验成员在微信中打开「体验版小程序」二维码或搜索体验版即可真机使用。

二维码生成：微信开发者工具「预览」可生成开发版真机预览二维码；体验版二维码在「版本管理」页获取/分享。

## 6. 正式发布（可选，后续）

1. 完善隐私指引与用户协议后，在「版本管理」→「开发版本」选择体验稳定版本 → 提交审核。
2. 审核通过后按提示发布（全量或分阶段）。
3. 发布前用 `integrated_code_mode` 浏览器对 Web 端 + 真机小程序跑通关键链路（登录/发布/地点评分/认证/作者徽标）。

## 7. 风险与注意事项

- 生产服务器需确保已 `seed_data.py` 重跑，包含最新演示数据（地点评分、campus_verified 等，见 B-07/A-08）。
- 小程序请求会命中生产环境登录限流（生产环境为严格限流），演示/测试时注意频控。
- 服务器暂未配置 Node.js，前端静态资源由本地 `npm run build` 后 SCP 上传；小程序为纯前端工程，无需服务器构建。
- 若域名/IP 变更，需同步更新 `miniprogram/services/request.ts` 的 `API_HOST` 与微信后台合法域名。
