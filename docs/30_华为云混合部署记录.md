# 此刻校园 - 华为云混合部署记录

> 日期：2026-07-05  
> 服务器：`huawei` / Ubuntu 22.04.5 LTS / ARM64  
> 域名：`campus.chaina1.com`

## 1. 部署方案

本次从 Docker Compose 全容器化方案切换为混合部署：

- openGauss：Docker 容器运行，镜像为 `opengauss:7.0.0-RC3`，仅绑定 `127.0.0.1:5432`
- 后端：物理部署，使用 `/opt/moment-campus/backend/.venv`，由 `systemd` 服务 `moment-backend` 管理
- 前端：本地构建 `frontend/dist` 后上传到服务器，由 Nginx 静态托管
- Nginx：监听 `0.0.0.0:80`，反代 `/api/`、`/health`、`/docs` 到 `127.0.0.1:8000`
