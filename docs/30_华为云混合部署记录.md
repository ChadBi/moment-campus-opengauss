## 7. 前端访问性能优化

2026-07-06 排查发现，生产环境虽然已经使用 `npm run build` 输出静态文件，但 Nginx 未对 `index.html` 与 `/assets/*` 配置明确缓存头；同时前端路由按页面懒加载，首次进入未访问过的页面时仍需要下载对应 JS chunk。

已补充优化策略：

- `index.html` 保持 `Cache-Control: no-cache, no-store, must-revalidate`，保证每次可以拿到最新入口文件
- `/assets/*` 与带 hash 的静态文件使用 `Cache-Control: public, max-age=31536000, immutable`
- Nginx 开启 gzip 压缩，减少 JS/CSS 传输体积
- 前端在首屏稳定后分批预取常用页面 chunk，地图页等较大的 chunk 延后预取，降低切换页面时的等待感

上线后应验证：

- `https://campus.chaina1.com/` 返回 `no-cache`
- `https://campus.chaina1.com/assets/*.js` 返回 `max-age=31536000, immutable`
- `/health` 与 `/api/v1/posts` 仍正常返回
