# 用户角色与场景

> 此刻校园 · Moment Campus  
> 版本：1.0  
> 最后更新：2026-06-18

## 1. 用户角色定义

### 1.1 角色概览

| 角色 | 描述 | 核心需求 | 使用频率 |
|------|------|----------|----------|
| 游客 | 未登录用户 | 浏览公开信息 | 低频 |
| 普通用户 | 已登录用户 | 发布、互动、收藏 | 中频 |
| 内容发布者 | 活跃的内容贡献者 | 高效发布、管理内容 | 高频 |
| 校园社团/组织 | 组织账号 | 发布活动信息 | 中频 |
| 便民服务提供者 | 校园服务商家 | 推广服务信息 | 中频 |
| 管理员 | 平台运营人员 | 内容审核、社区管理 | 高频 |

### 1.2 角色详细画像

#### 1.2.1 游客

**基本信息：**
- 未注册用户
- 可能是潜在用户
- 通过分享链接或搜索引擎进入

**核心需求：**
- 快速浏览校园信息
- 了解平台功能
- 判断是否值得注册

**痛点：**
- 无法发布和互动
- 功能受限
- 需要注册才能使用完整功能

**转化路径：**
游客 → 浏览信息 → 产生兴趣 → 注册账户 → 成为普通用户

#### 1.2.2 普通用户

**基本信息：**
- 在校学生、教职工
- 年龄 18-25 岁为主
- 移动端用户为主

**核心需求：**
- 查找校园信息（美食、服务、活动等）
- 发布校园信息
- 收藏感兴趣的内容
- 参与社区互动

**使用场景：**
- 新生入学，需要了解校园
- 在校学生，探索校园生活
- 查找特定服务（打印、维修等）
- 分享校园经验

**痛点：**
- 信息分散，难以查找
- 信息时效性难以判断
- 重复询问相同问题

#### 1.2.3 内容发布者

**基本信息：**
- 活跃的用户
- 愿意分享校园经验
- 有一定的内容创作能力

**核心需求：**
- 高效发布内容
- 管理已发布内容
- 获得社区反馈
- 建立个人影响力

**使用场景：**
- 发现新的美食窗口
- 分享校园活动信息
- 提供生活服务信息
- 记录校园生活

**痛点：**
- 发布流程复杂
- 内容管理不便
- 缺乏反馈机制

#### 1.2.4 校园社团/组织

**基本信息：**
- 学生会、社团负责人
- 需要发布活动信息
- 希望吸引更多参与

**核心需求：**
- 发布活动信息
- 宣传活动详情
- 招募参与者
- 展示组织形象

**使用场景：**
- 发布社团招新信息
- 宣传活动详情
- 分享活动回顾
- 建立组织品牌

**痛点：**
- 宣传渠道有限
- 信息传播范围小
- 难以触达目标用户

#### 1.2.5 便民服务提供者

**基本信息：**
- 校内打印店、维修店
- 配送服务提供者
- 其他校园服务商家

**核心需求：**
- 推广服务信息
- 吸引客户
- 建立口碑
- 更新服务状态

**使用场景：**
- 发布服务信息
- 更新价格和营业时间
- 回应客户评价
- 处理客户咨询

**痛点：**
- 宣传成本高
- 客户获取困难
- 信息更新不及时

#### 1.2.6 管理员

**基本信息：**
- 平台运营人员
- 负责内容审核
- 维护社区秩序

**核心需求：**
- 高效审核内容
- 处理举报
- 管理用户
- 维护社区氛围

**使用场景：**
- 审核新发布内容
- 处理用户举报
- 管理违规用户
- 维护分类和标签

**痛点：**
- 审核工作量大
- 举报处理效率低
- 缺乏管理工具

### 2.2 核心场景详述

#### S01：新生入学探索

**场景描述：** 刚入学的新生需要了解校园生活，查找食堂、自习室、服务设施等信息。

**用户故事：**
> 作为一名新生，我希望能够快速了解校园中有哪些好吃的食堂、适合自习的地方、以及生活服务设施，这样我可以更快适应校园生活。

**前置条件：**
- 用户已下载或访问平台
- 用户已选择所在校园

**主要步骤：**
1. 打开首页，浏览推荐信息
2. 进入发现页，按分类浏览
3. 查看"新生必备"专题（P1）
4. 使用地图查看附近信息
5. 查看信息详情
6. 收藏感兴趣的信息

**成功结果：**
- 用户找到需要的信息
- 用户收藏了感兴趣的内容
- 用户对校园有了基本了解

**失败情况：**
- 找不到需要的信息
- 信息已过时
- 信息不准确

**异常处理：**
- 无信息：显示空状态，引导用户发布
- 信息过期：显示有效性状态，提醒用户确认
- 网络错误：显示错误提示，提供重试按钮

**涉及页面：**
- 首页
- 发现页
- 地图页
- 信息详情页
- 个人中心

**涉及数据：**
- Post（信息）
- Category（分类）
- Location（地点）
- Favorite（收藏）

---

#### S02：查找美食信息

**场景描述：** 用户想查找校园中的美食信息，包括食堂窗口、餐厅、小吃等。

**用户故事：**
> 作为一名在校学生，我希望能够查找校园中有哪些好吃的食堂窗口和餐厅，这样我可以尝试新的美食。

**前置条件：**
- 用户已登录
- 用户已选择校园

**主要步骤：**
1. 进入发现页
2. 选择"校园美食"分类
3. 浏览美食信息列表
4. 使用筛选条件（距离、有效性等）
5. 查看信息详情
6. 查看其他用户的评价
7. 确认信息是否仍然有效

**成功结果：**
- 用户找到想吃的美食
- 用户了解价格和位置
- 用户确认信息有效

**失败情况：**
- 找不到想吃的美食
- 信息已过时
- 价格信息不准确

**异常处理：**
- 无结果：显示空状态，建议用户发布
- 信息过期：显示有效性状态
- 距离过远：显示距离信息

**涉及页面：**
- 发现页
- 分类详情页
- 信息详情页

**涉及数据：**
- Post（信息）
- Category（分类）
- Location（地点）
- ValidationRecord（有效性确认）

---

#### S03：发布美食推荐

**场景描述：** 用户发现了一个新的美食窗口，想分享给其他同学。

**用户故事：**
> 作为一名内容发布者，我希望能够快速发布我新发现的美食窗口信息，包括位置、价格、推荐菜品等，这样其他同学也可以尝试。

**前置条件：**
- 用户已登录
- 用户已选择校园

**主要步骤：**
1. 点击发布按钮
2. 选择"校园美食"分类
3. 选择或创建地点
4. 填写标题和描述
5. 上传图片
6. 添加标签（如"便宜"、"好吃"等）
7. 设置有效期
8. 预览信息
9. 发布

**成功结果：**
- 信息发布成功
- 其他用户可以查看
- 发布者获得反馈

**失败情况：**
- 必填项缺失
- 图片上传失败
- 包含敏感信息

**异常处理：**
- 必填项缺失：提示"请填写完整信息"
- 图片上传失败：提示"图片上传失败，请重试"
- 敏感信息：提示"检测到可能包含敏感信息，请检查"

**涉及页面：**
- 发布信息页
- 发布预览页
- 发布成功页

**涉及数据：**
- Post（信息）
- Category（分类）
- Location（地点）
- Tag（标签）
- PostImage（信息图片）

## 3. 用户旅程地图

### 3.1 新用户旅程

```
阶段：认知 → 注册 → 探索 → 发布 → 互动 → 留存

认知：
- 通过分享链接或搜索引擎进入
- 浏览公开信息
- 了解平台功能

注册：
- 点击注册按钮
- 填写注册信息
- 验证邮箱
- 选择校园

探索：
- 浏览首页推荐
- 按分类浏览
- 使用地图发现
- 搜索特定信息

发布：
- 发现值得分享的信息
- 点击发布按钮
- 填写发布信息
- 发布成功

互动：
- 点赞感兴趣的信息
- 收藏有用的信息
- 发表评论
- 确认信息有效性

留存：
- 定期查看新信息
- 管理收藏和发布
- 参与社区互动
- 成为活跃用户
```

### 3.2 内容发布者旅程

```
阶段：发现 → 创作 → 发布 → 反馈 → 迭代

发现：
- 发现新的美食窗口
- 参加有趣的校园活动
- 找到好的自习地点
- 发现便民服务

创作：
- 拍摄照片
- 撰写描述
- 整理信息
- 添加标签

发布：
- 选择分类
- 选择地点
- 填写信息
- 预览发布

反馈：
- 查看点赞数
- 查看评论
- 收到通知
- 了解有效性确认

迭代：
- 根据反馈改进
- 更新信息内容
- 回应评论
- 持续发布
```

### 3.3 管理员旅程

```
阶段：审核 → 处理 → 管理 → 优化

审核：
- 查看待审核内容
- 判断内容合规性
- 通过或拒绝
- 填写审核意见

处理：
- 处理用户举报
- 处理违规内容
- 处理用户申诉
- 记录操作日志

管理：
- 管理用户
- 管理分类和标签
- 管理专题
- 维护社区秩序

优化：
- 分析社区数据
- 优化审核流程
- 改进管理工具
- 提升用户体验
```

## 4. 用户痛点与解决方案

### 4.1 痛点分析

| 痛点 | 影响角色 | 严重程度 | 解决方案 |
|------|----------|----------|----------|
| 信息分散，难以查找 | 普通用户 | 高 | 分类浏览、搜索、地图发现 |
| 信息时效性难以判断 | 普通用户 | 高 | 有效性确认机制 |
| 重复询问相同问题 | 普通用户 | 中 | 信息沉淀、搜索 |
| 发布流程复杂 | 内容发布者 | 中 | 简化发布流程 |
| 内容管理不便 | 内容发布者 | 中 | 个人中心管理 |
| 缺乏反馈机制 | 内容发布者 | 低 | 点赞、评论、通知 |
| 审核工作量大 | 管理员 | 高 | 批量审核、自动审核（P2） |
| 举报处理效率低 | 管理员 | 中 | 优化举报处理流程 |

### 4.2 解决方案优先级

**P0 解决方案：**
- 分类浏览和搜索
- 有效性确认机制
- 简化发布流程
- 基础管理功能

**P1 解决方案：**
- 专题清单
- 浏览历史
- 草稿箱
- 修改建议

**P2 解决方案：**
- AI 语义搜索
- AI 标签推荐
- 智能过期判断
- 自动化审核
