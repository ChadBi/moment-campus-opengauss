# 产品需求文档 (PRD)

> 此刻校园 · Moment Campus  
> 版本：1.0  
> 最后更新：2026-06-18

## 1. 文档概述

### 1.1 文档目的

本文档详细描述"此刻校园"产品的功能需求、非功能需求、业务规则和约束条件，为设计、开发和测试提供明确的产品需求基线。

### 1.2 适用范围

本文档适用于产品、设计、开发、测试团队成员，以及项目相关利益方。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| 信息 | 用户发布的校园内容，包括美食、活动、服务等 |
| 地点 | 具有地理位置的校园场所 |
| 分类 | 信息的类型划分（如美食、活动、服务等） |
| 标签 | 用户自定义的关键词标记 |
| 有效性状态 | 信息的时效性状态（有效、可能过期、已过期、不确定） |
| 社区验证 | 用户通过确认、评论等方式共同维护信息准确性 |

## 2. 产品概述

### 2.1 产品愿景

打造一个由校园成员共同维护的、可持续更新的校园生活信息库，让有价值的校园信息不再随时间消失。

### 2.2 产品定位

**此刻校园**是一个校园信息共享与沉淀平台，结合地图与信息流两种发现方式，通过社区共同验证确保信息有效性。

### 2.3 核心价值主张

- **信息沉淀**：让有价值的校园信息长期存在
- **社区验证**：通过集体智慧确保信息准确性
- **地图发现**：基于地理位置发现附近信息
- **轻量发布**：简单几步即可完成信息发布
- **隐私保护**：不收集用户行动轨迹，尊重用户隐私

## 3. 用户角色

### 3.1 用户角色定义

详见 [用户角色与场景](02_user_roles_and_scenarios.md)

**主要角色：**

1. **游客**：未登录用户，可浏览公开信息
2. **普通用户**：已登录用户，可发布、互动
3. **内容发布者**：活跃的内容贡献者
4. **校园社团/组织**：发布活动信息的组织账号
5. **便民服务提供者**：提供校园服务的商家
6. **管理员**：负责内容审核和社区管理

## 4. 功能需求

### 4.1 功能优先级说明

- **P0**：第一版必须具备，核心功能
- **P1**：第一版尽量完成，增强功能
- **P2**：后续扩展，未来功能

详见 [功能范围与优先级](03_feature_scope_and_priority.md)

### 4.2 P0 功能需求（第一版必须）

#### 4.2.1 用户认证与账户管理

**FR-AUTH-001：用户注册**

- **描述**：用户可以通过邮箱/用户名注册账户
- **前置条件**：用户未登录
- **业务规则**：
  - 用户名长度 3-20 字符，仅允许字母、数字、下划线
  - 密码长度至少 8 位，必须包含字母和数字
  - 邮箱格式验证，需要邮箱验证（第一版可简化）
  - 用户名和邮箱唯一性校验
- **输入**：用户名、邮箱、密码、确认密码
- **输出**：注册成功跳转登录页，失败显示错误信息
- **异常处理**：
  - 用户名已存在：提示"用户名已被注册"
  - 邮箱已存在：提示"邮箱已被注册"
  - 密码不符合要求：提示具体要求
  - 网络错误：提示"注册失败，请稍后重试"

**FR-AUTH-002：用户登录**

- **描述**：用户可以通过用户名/邮箱和密码登录
- **前置条件**：用户已注册
- **业务规则**：
  - 支持用户名或邮箱登录
  - 登录失败 5 次后锁定账户 15 分钟
  - 登录状态保持 7 天（可配置）
  - 使用 JWT Token 进行身份认证
- **输入**：用户名/邮箱、密码
- **输出**：登录成功跳转首页，失败显示错误信息
- **异常处理**：
  - 账户不存在：提示"账户不存在"
  - 密码错误：提示"密码错误"
  - 账户被锁定：提示"账户已锁定，请 15 分钟后重试"
  - 账户被禁用：提示"账户已被禁用"

**FR-AUTH-003：用户登出**

- **描述**：用户可以退出登录状态
- **前置条件**：用户已登录
- **业务规则**：
  - 清除本地 Token
  - 跳转回首页或登录页
- **输入**：无
- **输出**：登出成功，跳转页面

**FR-AUTH-004：校园选择**

- **描述**：用户登录后需要选择所属校园
- **前置条件**：用户已登录，未选择校园
- **业务规则**：
  - 首次登录必须选择校园
  - 可以随时切换校园（P1 功能）
  - 校园列表按名称排序
  - 支持搜索校园
- **输入**：校园选择
- **输出**：保存校园选择，跳转首页

#### 4.2.2 信息浏览与发现

**FR-BROWSE-001：首页信息流**

- **描述**：展示推荐和最新的校园信息
- **前置条件**：无（游客可访问）
- **业务规则**：
  - 默认显示当前校园的信息
  - 按综合排序（考虑有效性、时间、距离、互动）
  - 分页加载，每页 20 条
  - 显示信息卡片：标题、分类、地点、时间、有效性状态、点赞数
  - 支持下拉刷新
- **输入**：校园 ID、分页参数
- **输出**：信息列表
- **异常处理**：
  - 无信息：显示空状态"暂无信息"
  - 网络错误：显示错误提示和重试按钮

**FR-BROWSE-002：分类浏览**

- **描述**：按分类浏览信息
- **前置条件**：无
- **业务规则**：
  - 显示所有分类及其图标
  - 点击分类进入分类详情页
  - 分类页显示该分类下的信息列表
  - 支持按时间、热度排序
- **输入**：分类 ID、排序方式、分页参数
- **输出**：分类信息列表

**FR-BROWSE-003：地图发现**

- **描述**：在地图上查看附近的信息
- **前置条件**：无
- **业务规则**：
  - 显示校园地图（使用 MapLibre GL JS 或 Leaflet）
  - 在地图上标记有信息的地点
  - 点击标记显示地点信息摘要
  - 支持缩放和拖动
  - 标记数量限制（避免性能问题，最多显示 100 个）
  - 根据缩放级别动态调整标记显示
- **输入**：地图边界坐标、缩放级别
- **输出**：地图标记列表

**FR-BROWSE-004：信息详情页**

- **描述**：查看信息的完整内容
- **前置条件**：无
- **业务规则**：
  - 显示完整信息：标题、分类、地点、描述、图片、标签、发布时间、有效期
  - 显示发布者信息（昵称、头像）
  - 显示有效性状态和确认人数
  - 显示点赞、收藏、评论数
  - 显示评论区（最新 10 条，可展开查看全部）
  - 根据用户权限显示操作按钮（编辑、删除、举报）
- **输入**：信息 ID
- **输出**：信息详情

**FR-BROWSE-005：地点详情页**

- **描述**：查看地点的详细信息和相关信息
- **前置条件**：无
- **业务规则**：
  - 显示地点名称、位置、描述
  - 显示该地点下的所有信息（按时间排序）
  - 显示地点统计信息（信息数量、访问量）
  - 支持在地图上查看地点位置
- **输入**：地点 ID
- **输出**：地点详情和相关信息列表

#### 4.2.3 搜索功能

**FR-SEARCH-001：关键词搜索**

- **描述**：通过关键词搜索信息
- **前置条件**：无
- **业务规则**：
  - 搜索范围：标题、正文、地点名称、分类名称、标签、发布者昵称
  - 支持模糊匹配
  - 搜索结果按综合排序
  - 支持筛选条件：分类、距离、发布时间、有效性状态、是否有图片
  - 支持排序方式：综合、距离最近、发布时间最新、热度最高
  - 分页加载，每页 20 条
  - 记录搜索历史（最近 10 条）
- **输入**：关键词、筛选条件、排序方式、分页参数
- **输出**：搜索结果列表
- **异常处理**：
  - 无结果：显示"未找到相关信息"
  - 网络错误：显示错误提示

#### 4.2.4 信息发布

**FR-POST-001：发布信息**

- **描述**：用户可以发布校园信息
- **前置条件**：用户已登录，已选择校园
- **业务规则**：
  - 发布流程：选择分类 → 选择地点 → 填写标题和描述 → 上传图片 → 添加标签 → 设置有效期 → 预览 → 发布
  - 标题：必填，长度 5-100 字符
  - 描述：必填，长度 10-5000 字符
  - 分类：必填，从预定义分类中选择
  - 地点：必填，可选择已有地点或创建新地点
  - 图片：选填，最多 9 张，每张不超过 5MB
  - 标签：选填，最多 5 个，每个标签 2-20 字符
  - 有效期：选填，可选择类型（永久、短期、自定义日期）
  - 匿名发布：选填，发布后不显示发布者信息
  - 发布前检查敏感信息（手机号、身份证号等）
  - 发布后状态为"待审核"（如开启审核）或"已发布"
- **输入**：信息表单数据
- **输出**：发布成功，跳转信息详情页
- **异常处理**：
  - 必填项缺失：提示"请填写完整信息"
  - 图片上传失败：提示"图片上传失败，请重试"
  - 包含敏感信息：提示"检测到可能包含敏感信息，请检查"
  - 网络错误：提示"发布失败，请稍后重试"

**FR-POST-002：编辑信息**

- **描述**：用户可以编辑自己发布的信息
- **前置条件**：用户已登录，信息为当前用户发布
- **业务规则**：
  - 只能编辑自己的信息
  - 编辑后状态变为"待审核"（如开启审核）或保持"已发布"
  - 编辑历史记录（可选，P1 功能）
- **输入**：信息 ID、更新后的表单数据
- **输出**：编辑成功，跳转信息详情页

**FR-POST-003：删除信息**

- **描述**：用户可以删除自己发布的信息
- **前置条件**：用户已登录，信息为当前用户发布
- **业务规则**：
  - 只能删除自己的信息
  - 软删除（标记为已删除，不物理删除）
  - 删除后不可恢复（提示用户确认）
  - 删除后相关的评论、点赞、收藏一并软删除
- **输入**：信息 ID
- **输出**：删除成功，跳转回上一页

**FR-POST-004：保存草稿**

- **描述**：用户可以保存未完成的发布信息
- **前置条件**：用户已登录
- **业务规则**：
  - 草稿自动保存（每 30 秒或内容变化时）
  - 手动保存按钮
  - 草稿箱显示所有草稿
  - 草稿可以编辑、发布、删除
  - 草稿数量限制（最多 50 个）
- **输入**：草稿数据
- **输出**：保存成功，显示提示

#### 4.2.5 互动功能

**FR-INTERACT-001：点赞**

- **描述**：用户可以对信息点赞
- **前置条件**：用户已登录
- **业务规则**：
  - 每个用户对每条信息只能点赞一次
  - 可以取消点赞
  - 实时更新点赞数
  - 点赞记录保存在用户账户中
- **输入**：信息 ID
- **输出**：点赞成功，更新点赞数

**FR-INTERACT-002：收藏**

- **描述**：用户可以收藏感兴趣的信息
- **前置条件**：用户已登录
- **业务规则**：
  - 每个用户对每条信息只能收藏一次
  - 可以取消收藏
  - 收藏记录保存在用户账户中
  - 收藏列表按时间倒序排列
- **输入**：信息 ID
- **输出**：收藏成功，更新收藏状态

**FR-INTERACT-003：评论**

- **描述**：用户可以对信息发表评论
- **前置条件**：用户已登录
- **业务规则**：
  - 评论内容长度 1-1000 字符
  - 支持回复其他评论（最多 2 级）
  - 评论按时间倒序排列
  - 可以删除自己的评论
  - 评论数实时更新
  - 评论支持匿名（P1 功能）
- **输入**：信息 ID、评论内容、父评论 ID（可选）
- **输出**：评论成功，更新评论列表

**FR-INTERACT-004：有效性确认**

- **描述**：用户可以确认信息是否仍然有效
- **前置条件**：用户已登录
- **业务规则**：
  - 确认选项：仍然有效、已经失效、暂时无法确认
  - 每个用户可以多次确认，但保留历史记录
  - 根据确认结果更新信息的有效性状态
  - 有效性状态影响搜索和推荐权重
  - 显示确认统计（有效人数、失效人数）
- **输入**：信息 ID、确认类型
- **输出**：确认成功，更新有效性状态

**FR-INTERACT-005：举报**

- **描述**：用户可以举报违规内容
- **前置条件**：用户已登录
- **业务规则**：
  - 举报类型：虚假信息、广告推广、隐私泄露、违法违规、其他
  - 举报说明：选填，长度 0-500 字符
  - 每个用户对每条内容只能举报一次
  - 举报后进入管理员审核队列
  - 举报处理结果通知用户（P1 功能）
- **输入**：信息 ID、举报类型、举报说明
- **输出**：举报成功，显示提示

#### 4.2.6 个人中心

**FR-USER-001：个人资料**

- **描述**：用户可以查看和编辑个人资料
- **前置条件**：用户已登录
- **业务规则**：
  - 显示用户基本信息：昵称、头像、个人简介
  - 显示统计信息：发布数、收藏数、获赞数
  - 可以编辑昵称、头像、个人简介
  - 昵称长度 2-20 字符
  - 头像支持上传（不超过 2MB）
- **输入**：用户资料数据
- **输出**：更新成功，显示新资料

**FR-USER-002：我的发布**

- **描述**：查看用户发布的所有信息
- **前置条件**：用户已登录
- **业务规则**：
  - 显示当前用户发布的所有信息（包括已删除的）
  - 按时间倒序排列
  - 显示信息状态（已发布、待审核、已拒绝、已删除）
  - 支持编辑、删除操作
- **输入**：分页参数
- **输出**：发布信息列表

**FR-USER-003：我的收藏**

- **描述**：查看用户收藏的所有信息
- **前置条件**：用户已登录
- **业务规则**：
  - 显示当前用户收藏的所有信息
  - 按收藏时间倒序排列
  - 支持取消收藏
  - 收藏的信息被删除时，从收藏列表中移除
- **输入**：分页参数
- **输出**：收藏信息列表

**FR-USER-004：消息通知**

- **描述**：查看用户的通知消息
- **前置条件**：用户已登录
- **业务规则**：
  - 通知类型：评论通知、点赞通知、系统通知、审核通知
  - 未读通知显示红点标记
  - 点击通知跳转相关内容
  - 标记已读/未读
  - 通知列表按时间倒序排列
  - 通知保留时间：30 天
- **输入**：分页参数
- **输出**：通知列表

### 4.3 P1 功能需求（第一版尽量完成）

#### 4.3.1 专题清单

**FR-TOPIC-001：专题清单**

- **描述**：创建和浏览主题化的信息集合
- **前置条件**：无（浏览），用户已登录（创建）
- **业务规则**：
  - 专题包含：标题、描述、封面图、信息列表
  - 专题可以由管理员或普通用户创建
  - 专题可以公开或私有
  - 专题信息可以手动添加或自动聚合
  - 专题列表按热度排序
- **输入**：专题数据
- **输出**：专题详情和相关信息

#### 4.3.2 浏览历史

**FR-HISTORY-001：浏览历史**

- **描述**：记录用户浏览过的信息
- **前置条件**：用户已登录
- **业务规则**：
  - 自动记录浏览历史
  - 保留最近 100 条记录
  - 按浏览时间倒序排列
  - 支持清除历史记录
  - 历史记录不公开显示
- **输入**：无（自动记录）
- **输出**：浏览历史列表

#### 4.3.3 草稿箱

**FR-DRAFT-001：草稿箱**

- **描述**：管理用户保存的草稿

## 6. 业务规则

### 6.1 信息有效性规则

**BR-VALID-001：有效性状态**

- **有效 (valid)**：信息确认有效，正常展示
- **可能过期 (possibly_expired)**：超过有效期或收到失效反馈，提醒用户确认
- **已过期 (expired)**：确认已过期，降低展示权重
- **不确定 (uncertain)**：无法判断有效性，正常展示

**BR-VALID-002：有效性判断**

- 用户确认"仍然有效"：更新为有效状态
- 用户确认"已经失效"：更新为已过期状态
- 超过有效期：自动标记为可能过期
- 收到 3 个以上失效反馈：标记为可能过期
- 管理员可以手动修改有效性状态

**BR-VALID-003：有效性展示**

- 有效信息：显示绿色标识"有效"
- 可能过期信息：显示黄色标识"可能过期"
- 已过期信息：显示红色标识"已过期"
- 不确定信息：显示灰色标识"不确定"

### 6.2 内容审核规则

**BR-MOD-001：审核状态**

- **草稿 (draft)**：用户保存的草稿
- **待审核 (pending)**：等待管理员审核
- **已发布 (published)**：审核通过，正常展示
- **已拒绝 (rejected)**：审核未通过，不展示
- **已隐藏 (hidden)**：管理员手动隐藏
- **已删除 (deleted)**：软删除，不展示

**BR-MOD-002：审核流程**

- 用户发布信息 → 状态为"待审核"
- 管理员审核 → 通过（已发布）或拒绝（已拒绝）
- 管理员可以手动隐藏已发布的内容
- 用户可以删除自己的内容

**BR-MOD-003：审核标准**

- 内容真实、准确
- 不包含虚假信息
- 不包含广告推广
- 不包含隐私信息
- 不包含违法违规内容
- 符合社区规范

### 6.3 社区治理规则

**BR-GOV-001：举报处理**

- 用户举报 → 进入审核队列
- 管理员审核 → 处理（删除、隐藏、警告）或驳回
- 处理结果通知举报者（P1 功能）

**BR-GOV-002：违规处罚**

- 第一次违规：警告
- 第二次违规：禁言 7 天
- 第三次违规：永久封禁
- 管理员可以手动调整处罚

**BR-GOV-003：匿名发布**

- 用户可以选择匿名发布
- 匿名发布不显示发布者信息
- 数据库中仍保存发布者信息（用于审计）
- 匿名信息被举报时，管理员可以查看发布者

### 6.4 搜索排序规则

**BR-SORT-001：综合排序算法**

```
综合得分 = 
  有效性得分 * 0.3 +      # 有效信息得分高
  时间得分 * 0.25 +        # 新信息得分高
  距离得分 * 0.2 +         # 近距离信息得分高
  互动得分 * 0.15 +        # 点赞、评论、收藏
  质量得分 * 0.1           # 图片数量、描述长度
```

**BR-SORT-002：距离排序**

- 需要用户授权位置
- 计算直线距离
- 距离 < 1km：显示"xxx 米"
- 距离 ≥ 1km：显示"x.x 公里"

**BR-SORT-003：热度排序**

```
热度 = 点赞数 * 2 + 评论数 * 3 + 浏览量 * 0.1
```

### 6.5 图片处理规则

**BR-IMG-001：图片上传**

- 支持格式：JPG、PNG、GIF
- 单张图片 ≤ 5MB
- 每条信息最多 9 张图片
- 自动压缩（宽度最大 1920px）
- 生成缩略图（300x300）

**BR-IMG-002：图片展示**

- 信息详情：显示所有图片，支持滑动查看
- 图片加载：使用懒加载

### 6.6 通知规则

**BR-NOTIF-001：通知类型**

- **评论通知**：有人评论了你的信息
- **回复通知**：有人回复了你的评论
- **点赞通知**：有人点赞了你的信息
- **系统通知**：系统消息（审核结果、违规通知等）

```json
  "code": 0,
  "message": "success",
  "data": {}
}
```

**错误响应：**

```json
{
  "code": 10001,
  "message": "错误说明",
  "data": null
}
```
