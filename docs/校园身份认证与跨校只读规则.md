# 校园身份认证与跨校只读规则

## 规则

1. 用户注册时选择的学校保存为 `registration_school_id`，该字段不会随学校切换改变。
2. `school_id` 继续表示用户当前访问/默认的学校，用于兼容现有租户上下文和数据隔离。
3. 校园身份认证只在 `registration_school_id` 对应的学校开放，认证验证码也只绑定该学校。
4. 普通用户在其他已加入学校只能浏览公开内容；发布、评论、点赞、协同验证、地点评价、地点资料提议和新增地点均被拒绝。
5. 切回注册学校后，原 `campus_verified` 状态恢复可用，不需要重复认证。
6. `super_admin` 和学校管理员继续遵循现有角色权限体系；本规则主要限制普通用户的跨校写操作。

## 前端表现

- 非注册学校不显示校园认证卡片，也不显示个人资料的“已认证”标识。
- 发布、评论、评价等写入区域显示“当前学校仅支持浏览”，并引导用户切回注册学校。
- 个人资料页保留学校切换入口，明确提示注册学校可认证、其他学校仅可浏览。

## 数据迁移

迁移 `o3p4q5r6s7t8_add_registration_school_id` 新增字段并将历史用户的 `school_id` 回填到 `registration_school_id`。字段暂时允许为空，以兼容直接构造的历史测试用户；运行迁移后正式用户均有注册学校值。
