# 页面规格说明

> 此刻校园 · Moment Campus  
> 版本：2.0（地图优先优化版）  
> 最后更新：2026-06-18

## 1. 文档概述

### 1.1 文档目的

本文档详细描述"此刻校园"平台所有页面的规格说明，包括页面目标、组成结构、核心信息、操作逻辑、状态处理和页面关系，为 UI 设计和前端开发提供明确指引。

### 1.2 设计规范

**颜色规范：**

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | #2F7D5A | 品牌色、主要操作按钮 |
| 主色浅色 | #E8F3ED | 选中状态、浅色背景 |
| 背景 | #F7F8F5 | 页面背景色 |
| 内容背景 | #FFFFFF | 卡片、内容区域背景 |
| 主文字 | #17211C | 标题、正文 |
| 次文字 | #66736C | 辅助文字、说明文字 |
| 边框 | #DDE5E0 | 分割线、边框 |
| 暖黄色 | #F2B85B | 提醒、警告、可能过期状态 |
| 失效红色 | #D76565 | 错误、已过期状态、删除操作 |
| 信息蓝色 | #5C83B5 | 信息提示、链接 |

**设计原则：**

- **地图优先**：地图是核心交互区域，占据主要视觉空间
- 信息优先：快速传达核心信息
- 移动端优先：响应式设计，触摸友好
- 状态清晰：加载、空、错误状态明确
- 操作简洁：减少用户操作步骤

## 2. 用户端页面（29个）

### 2.1 欢迎页

**页面目标**

展示品牌形象和核心功能，引导用户登录或注册。

**进入方式**

- 首次打开应用
- 未登录状态访问任意页面

**页面组成**

1. **品牌展示区**：Logo、产品名称、Slogan
2. **功能介绍区**：3-4个核心功能卡片（地图发现、信息流、社区验证、轻量发布）
3. **操作入口区**：登录按钮、注册按钮

**核心信息**

- 产品名称和 Logo
- 核心价值主张
- 核心功能亮点

**核心操作**

- 点击登录按钮 → 登录页
- 点击注册按钮 → 注册页
- 滑动查看功能介绍

**页面状态**

- **加载中**：显示品牌 Logo 和加载动画
- **正常**：展示品牌信息和功能介绍
- **空**：不适用

**异常状态**

- 网络错误：不影响页面展示，登录/注册时提示错误

**空状态**

不适用

**移动端表现**

- 全屏展示，功能介绍可左右滑动
- 底部固定登录/注册按钮

**与其他页面的关系**

- → 登录页
- → 注册页
- → 首页（已登录用户自动跳转）

### 2.2 登录页

**页面目标**

用户通过用户名/邮箱和密码登录系统。

**进入方式**

- 欢迎页点击登录
- 未登录状态访问需要登录的功能

**页面组成**

1. **表单区**：用户名/邮箱输入框、密码输入框、登录按钮
2. **辅助操作区**：忘记密码链接、注册入口
3. **品牌区**：Logo 和 Slogan（可选）

**核心信息**

- 用户名/邮箱输入框
- 密码输入框
- 登录按钮

**核心操作**

- 输入用户名/邮箱
- 输入密码
- 点击登录按钮
- 点击注册入口 → 注册页

**页面状态**

- **加载中**：登录按钮显示加载状态，禁用表单
- **正常**：表单可编辑
- **空**：不适用

**异常状态**

- **网络错误**：提示"网络错误，请稍后重试"，提供重试按钮
- **账户不存在**：提示"账户不存在"
- **密码错误**：提示"密码错误"
- **账户锁定**：提示"账户已锁定，请15分钟后重试"
- **账户禁用**：提示"账户已被禁用"

**空状态**

不适用

**移动端表现**

- 表单占满屏幕宽度
- 键盘弹出时自动调整布局
- 支持指纹/面容登录（P2）

**与其他页面的关系**

- ← 欢迎页
- ← 注册页
- → 首页（登录成功）
- → 注册页（点击注册入口）

### 2.3 注册页

**页面目标**

用户通过用户名、邮箱和密码注册账户。

**进入方式**

- 欢迎页点击注册
- 登录页点击注册入口

**页面组成**

1. **表单区**：用户名输入框、邮箱输入框、密码输入框、确认密码输入框、注册按钮
2. **协议区**：用户协议和隐私政策勾选
3. **辅助操作区**：登录入口

**核心信息**

- 用户名输入框（3-20字符，字母数字下划线）
- 邮箱输入框
- 密码输入框（至少8位，包含字母和数字）
- 确认密码输入框

**核心操作**

- 输入用户名
- 输入邮箱
- 输入密码
- 确认密码
- 勾选用户协议
- 点击注册按钮

**页面状态**

- **加载中**：注册按钮显示加载状态
- **正常**：表单可编辑
- **空**：不适用

**异常状态**

- **网络错误**：提示"注册失败，请稍后重试"
- **用户名已存在**：提示"用户名已被注册"
- **邮箱已存在**：提示"邮箱已被注册"
- **密码不符合要求**：实时提示具体要求
- **格式错误**：实时提示格式要求

**空状态**

不适用

**移动端表现**

- 表单纵向排列
- 实时验证反馈
- 键盘类型自动切换（邮箱键盘、数字键盘）

**与其他页面的关系**

- ← 欢迎页
- ← 登录页
- → 登录页（注册成功）
- → 登录页（点击登录入口）

### 2.5 地图首页（原首页）

**页面目标**

以校园地图为主体，展示校园内各类信息点位，支持地图交互和信息发现。

**进入方式**

- 底部导航栏"地图"（默认首页）
- 登录成功后
- 选择校园后

**页面组成**

1. **地图区域**：占屏幕 70-80% 面积，显示校园地图和信息标记点
2. **顶部搜索栏**：浮动在地图上方，支持关键词搜索
3. **分类筛选区**：横向滚动的分类按钮，浮动在地图上方
4. **视图切换按钮**：右上角"地图/列表"切换按钮
5. **定位按钮**：右下角定位到当前位置
6. **底部信息卡片**：点击标记后从底部弹出信息摘要卡片（可拖动展开）
7. **底部导航栏**：地图、发现、发布、消息、我的

**核心信息**

- 校园地图（MapLibre GL JS）
- 信息标记点（按分类显示不同颜色和图标）
- 搜索入口
- 分类筛选按钮

**核心操作**

- 缩放和拖动地图
- 点击分类筛选按钮 → 筛选对应类型标记
- 点击地图标记 → 显示底部信息摘要卡片
- 点击信息摘要卡片 → 信息详情页
- 点击搜索入口 → 搜索页
- 点击视图切换 → 列表模式页
- 点击定位按钮 → 定位到当前位置
- 下拉刷新地图数据

**页面状态**

- **加载中**：地图加载动画
- **正常**：显示地图和标记点
- **空**：无标记点

**异常状态**

- **地图加载失败**：提示"地图加载失败"，提供重试按钮
- **位置授权失败**：提示"请授权位置权限"
- **标记过多**：限制显示 100 个标记，提示"缩小地图查看更多"

**空状态**

- **文案**："该区域暂无信息"
- **引导操作**："去发布第一条信息"按钮

**移动端表现**

- 地图占满屏幕（除顶部搜索栏和底部导航）
- 分类筛选按钮浮动在地图上方，横向滚动
- 标记摘要卡片从底部弹出，可拖动展开
- 支持双指缩放和拖动

**桌面端表现**

- 地图占据中间主要内容区
- 左侧分类导航栏
- 右侧推荐栏
- 支持鼠标滚轮缩放和拖动

**与其他页面的关系**

- → 搜索页
- → 信息详情页
- → 地点详情页
- → 列表模式页
- → 发现页（底部导航）
- → 发布信息页（底部导航）
- → 消息通知页（底部导航）
- → 个人中心（底部导航）

### 2.11 信息详情页

**页面目标**

展示信息的完整内容，提供互动和评论功能。

**进入方式**

- 信息列表点击信息卡片
- 搜索结果点击信息
- 地图标记点击

**页面组成**

1. **内容区**：标题、分类、地点、描述、图片轮播、标签、发布时间、有效期
2. **发布者区**：头像、昵称、发布时间
3. **有效性区**：有效性状态、确认人数、确认按钮
4. **互动区**：点赞、收藏、评论数、分享
5. **评论区**：最新10条评论、查看全部按钮
6. **操作区**：编辑、删除（仅发布者）、举报

**核心信息**

- 信息完整内容
- 发布者信息
- 有效性状态
- 互动数据
- 评论列表

**核心操作**

## 4. 附录

### 4.1 页面状态说明

**加载中状态**

- 使用骨架屏（Skeleton）展示页面结构
- 避免使用全屏Loading
- 加载时间超过3秒显示"加载时间较长"提示

**正常状态**

- 数据正常展示
- 交互功能可用
- 无错误提示

**空状态**

- 显示空状态插图
- 提供友好的文案提示
- 提供引导操作（如适用）

### 4.2 异常状态说明

**网络错误**

- 显示友好的错误提示
- 提供重试按钮
- 保留用户已输入的数据

**权限不足**

- 提示"权限不足"
- 隐藏无权限的操作按钮
- 管理员功能跳转登录页

**数据不存在**

- 提示"数据不存在"或"已被删除"
- 提供返回上一页按钮

### 4.3 移动端适配说明

**响应式断点**

- 移动端：< 768px
- 桌面端：≥ 768px

**移动端优化**

- 触摸目标最小 44x44px
- 支持手势操作（滑动、缩放）
- 键盘弹出时自动调整布局
- 使用原生组件（如日期选择器）

**性能优化**

- 图片懒加载
- 列表虚拟滚动
- 分页加载
- 缓存策略
