# Qwen-Audio-3.0-TTS-Plus 旁白生成方案

> 模型：`qwen-audio-3.0-tts-plus` | 平台：阿里云百炼 DashScope
> 模型页面：https://www.qianwenai.com/models/qwen-audio-3.0-tts-plus
> API 文档：https://help.aliyun.com/zh/model-studio/non-realtime-tts-user-guide
> 用途：为作品演示视频（~840字）和个人介绍视频（~360字）生成 AI 旁白
> 预估费用：约 ¥0.17（1201字 × ¥1.4/万字符）

---

## 一、模型能力概览

`qwen-audio-3.0-tts-plus` 是阿里通义千问面向高质量语音合成的旗舰模型，Plus 版本强调音质、自然度和表现力。关键能力：

| 能力 | 说明 |
|---|---|
| 音质 | 比Flash版本更高，适用于影视配音、有声书等专业场景 |
| 指令控制 | 支持自然语言指令控制语速、情绪、风格（如"沉稳有力，适合产品介绍"） |
| 声音复刻 | 可用音频样本复刻自定义音色 |
| 多语言 | 中文（普通话）、英文，支持中文方言 |
| 双协议 | 同时支持 WebSocket（实时）和 HTTP（非实时）两种接入方式 |
| 定价 | ¥1.4/万字符 |
| 速率限制 | 180 RPM（每分钟请求数） |

> 注意：Qwen-Audio-TTS 非实时语音合成仅在北京地域可用。

## 二、两种调用方式

### 方式 A：DashScope SDK（WebSocket，推荐）

模型页面推荐的官方调用方式，通过 DashScope SDK 的 `SpeechSynthesizer` 类完成。

**优点**：代码简洁，返回音频字节直接写文件，无需手动下载 URL。

**输出格式**：MP3（默认）

```python
import dashscope
from dashscope.audio.tts_v2 import SpeechSynthesizer

dashscope.api_key = "sk-你的API密钥"
dashscope.base_websocket_api_url = "wss://dashscope.aliyuncs.com/api-ws/v1/inference"

synthesizer = SpeechSynthesizer(
    model="qwen-audio-3.0-tts-plus",
    voice="longanhuan_v3.6"
)
audio = synthesizer.call("此刻校园，给信息一个坐标，给此刻一个归属。")

with open("output.mp3", "wb") as f:
    f.write(audio)
```

### 方式 B：HTTP REST API（非实时，备选）

适用于批量处理、不需要实时反馈的场景。

**优点**：支持 WAV 格式输出，返回音频 URL（有效期 24 小时）。

**输出格式**：WAV / MP3

```bash
curl -X POST https://dashscope.aliyuncs.com/api/v1/services/audio/tts/SpeechSynthesizer \
  -H "Authorization: Bearer $DASHSCOPE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen-audio-3.0-tts-plus",
    "input": {
      "text": "此刻校园，给信息一个坐标，给此刻一个归属。",
      "voice": "longanhuan_v3.6",
      "format": "wav",
      "sample_rate": 24000
    }
  }'
```

返回结构（非流式）：

```json
{
  "output": {
    "audio": {
      "url": "https://dashscope-result-xxx.oss-cn-beijing.aliyuncs.com/xxx.wav"
    }
  }
}
```

> 自动化脚本中两种方式均已实现：优先使用 SDK，失败后自动回退到 REST API。

## 三、准备工作

### 1. 获取 API Key

1. 前往阿里云百炼控制台：https://help.aliyun.com/zh/model-studio/get-api-key
2. 创建 API Key（格式 `sk-xxx`）
3. 在 PowerShell 中设置环境变量：

```powershell
$env:DASHSCOPE_API_KEY = "sk-你的API密钥"
```

### 2. 安装依赖

```powershell
pip install dashscope requests
```

> `dashscope` 是阿里云百炼官方 SDK，`requests` 用于 REST API 回退方式。
> 如果只安装了 `requests` 而没有 `dashscope`，脚本会自动使用 REST API 方式。

### 3. 音色选择

Qwen-Audio-TTS 系列支持系统音色，以下为推荐音色：

| 音色 ID | 风格 | 适用场景 |
|---|---|---|
| `longanhuan_v3.6` | 男声，沉稳厚重 | 作品演示视频旁白（推荐） |
| `longanyang` | 女声，温柔知性 | 个人介绍视频旁白（可选） |

> 完整音色列表请查看：https://help.aliyun.com/zh/model-studio/non-realtime-tts-user-guide
> 建议先用短文本试听不同音色，选择最合适的。
> 两个视频建议使用同一个音色，保持品牌一致性。

### 4. 关键参数说明

| 参数 | SDK 方式 | REST API 方式 | 说明 |
|---|---|---|---|
| model | `qwen-audio-3.0-tts-plus` | `qwen-audio-3.0-tts-plus` | Plus 版本，更高音质 |
| voice | `longanhuan_v3.6` | `longanhuan_v3.6` | 系统音色 ID |
| format | MP3（默认） | `wav` 可指定 | 输出音频格式 |
| sample_rate | — | `24000` | 采样率，24kHz 足够人声 |

## 四、生成策略

### 分段原则

- 按视频脚本的**每个时间段落**单独生成一段音频
- 这样可以在剪映中精确对齐画面和旁白
- 如果某段旁白太长（>200字），拆成 2 个请求

### 两个视频的旁白分段

**作品演示视频（10段）：**

| 段号 | 时间段 | 旁白字数 | 内容摘要 |
|---|---|---|---|
| D1 | 0:00-0:25 | ~85字 | 痛点引入 |
| D2 | 0:25-0:45 | ~55字 | 产品定位 |
| D3 | 0:45-1:20 | ~70字 | 地图与信息流 |
| D4 | 1:20-2:10 | ~120字 | AI语义搜索 |
| D5 | 2:10-3:00 | ~90字 | AI辅助发布 |
| D6 | 3:00-3:35 | ~90字 | 协同验证 |
| D7 | 3:35-4:05 | ~110字 | 后台管理系统 |
| D8 | 4:05-4:25 | ~110字 | 社会价值 |
| D9 | 4:25-4:35 | ~20字 | TRAE闪现 |
| D10 | 4:35-4:45 | ~45字 | 多学校与收尾 |

**个人介绍视频（4段）：**

| 段号 | 时间段 | 旁白字数 | 内容摘要 |
|---|---|---|---|
| P1 | 0:00-0:15 | ~35字 | 自我介绍 |
| P2 | 0:15-0:45 | ~110字 | 创作故事 |
| P3 | 0:45-1:05 | ~85字 | 参赛动机 |
| P4 | 1:05-1:20 | ~40字 | 参赛宣言 |

2. 导入对应的旁白音频文件
3. 按脚本时间段对齐音频和画面
4. 如音频时长与画面不匹配，用剪映的"变速"功能微调（0.8x-1.2x）
5. 添加背景音乐（音量调至旁白的 15-20%）
6. 生成字幕（剪映自动字幕 + 手动校对）

## 六、注意事项

1. **API Key 安全**：不要把密钥写入脚本或提交到 Git，始终用环境变量
2. **地域限制**：Qwen-Audio-TTS 仅在北京地域可用，API Key 需为北京地域的
3. **音频 URL 有效期**：REST API 返回的音频 URL 有效期 24 小时，脚本会自动下载到本地
4. **重试机制**：如某段生成失败，可单独重新运行该段（脚本会跳过已生成的文件）
5. **音色一致性**：两个视频建议使用同一个音色（`longanhuan_v3.6`），保持品牌一致性
6. **语速调整**：如觉得语速不合适，可在剪映中用"变速"功能调整
7. **费用极低**：总计约 1200 字，费用约 ¥0.17，可放心多次生成
