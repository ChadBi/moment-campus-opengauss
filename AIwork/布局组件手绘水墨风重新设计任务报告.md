# 任务报告：布局组件手绘水墨风重新设计

## 1. 任务概述

重新设计 `frontend/src/components/layout/` 下的 4 个布局组件（MainLayout、Sidebar、Header、MobileNav），使其符合手绘水墨风格。设计参考来自 `此刻校园_可演示Demo.html`，采用湖水蓝主色、灯笼橙强调色、纸张白/雾色背景、楷体标题、大圆角与柔和墨色阴影。

## 2. 已完成内容

- **MainLayout.tsx**：改为 app-shell 网格布局（桌面端 `88px + 1fr` 双栏），Sidebar 在左、Header+main 在右；移动端单栏 + 底部导航。
- **Sidebar.tsx**：88px 固定窄边栏，深湖蓝(`bg-lake`)底；52x52 白色圆角品牌标志（楷体"此"字 + 灯笼橙弧线装饰）；垂直导航按钮（图标+小字，激活态白底湖蓝字）；底部灯笼橙头像按钮；移动端抽屉弹出。
- **Header.tsx**：楷体品牌"此刻校园"+ 副标题；大圆角(18px)半透明白底搜索框（左侧搜索图标 + 右侧"⌘ K"提示）；44x44 圆角14px 图标按钮；灯笼橙发布按钮（带 `shadow-lamp`）；通知铃铛带计数徽章。
- **MobileNav.tsx**：固定底部，圆角20px，深湖蓝半透明(`bg-lake/[0.94]`)背景 + 毛玻璃；4 个导航项（首页、地图、发布、我的），激活态白底湖蓝字。

## 3. 未完成内容

暂无。

## 4. 实现思路

1. **阅读 Demo HTML** 提取关键设计元素：CSS 变量、布局结构（app-shell grid）、组件样式（sidebar/topbar/bottom-nav）。
2. **对照 Tailwind 配置** 确认可用色系（lake/lamp/ink/paper/mist/line）、字体（font-display/font-sans/font-data）、圆角（rounded-sm~xl）、阴影（shadow-sm/md/lg/lamp/lake）。
3. **保持接口兼容**：
   - Header props 不变（onMenuClick, user, notificationCount）
   - Sidebar props 不变（isOpen, onClose, categories）— categories 接受但不渲染（88px 窄边栏无空间，Demo 中分类在内容区面板展示）
   - MobileNav 保持 `{path, label, icon}` 结构，导航项调整为 4 项（通知移至 Header）
   - MainLayout props 不变（user, notificationCount, categories）
4. **响应式策略**：桌面端 `md:grid md:grid-cols-[88px_minmax(0,1fr)]`；Sidebar 用 `fixed`（移动抽屉）+ `md:sticky`（桌面固定）；Header 搜索框桌面行内 + 移动端独占一行（`col-span-2`）。
5. **z-index 层级**：Sidebar 抽屉 z-50 > 遮罩 z-40 > Header/MobileNav z-30。
