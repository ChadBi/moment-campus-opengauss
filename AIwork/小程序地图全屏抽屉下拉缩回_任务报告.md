# 任务报告：小程序地图全屏抽屉下拉缩回

## 1. 任务概述

补齐地图地点抽屉的反向交互，使其从半屏上滑进入全屏后，还能在内容顶部通过下拉手势跟手缩回半屏。

## 2. 已完成内容

- 删除全屏状态在触摸处理函数中的直接返回逻辑。
- 记录统一内容 `scroll-view` 的实时滚动位置。
- 全屏且内容位于顶部时，下拉手势驱动整张抽屉的 `translate3d` 位移。
- 下拉达到阈值后缩回半屏；未达到阈值则回弹到全屏。
- 内容未滚动到顶部时不接管手势，继续使用原生内容滚动。
- 禁用 iOS `scroll-view` 边缘回弹，避免内容橡皮筋效果与抽屉下拉位移叠加。
- 地点切换、学校切换、关闭抽屉和成功缩回时同步重置抽屉滚动状态。

## 3. 未完成内容

无法代替用户在其实体手机上完成手指触摸复测；代码已通过微信开发者工具真实触摸事件自动化验证，仍需用户重新编译后确认手机端手感。

## 4. 实现思路

抽屉只保留一个完整的 `scroll-view`。半屏时内容不滚动，手势控制整张抽屉；全屏时内容正常滚动。全屏触摸开始后，根据 `scrollTop` 分流：大于 1px 时不接管；位于顶部且手势向下时切换为抽屉拖动。松手时根据位移阈值决定缩回半屏或回弹全屏，从而避免出现内外两层独立滚动区域。

## 7. 测试与验证

- `npm run typecheck`：通过。
- `npm run test:format`：通过。
- 微信开发者工具 `compile_wxml pages/map/map.wxml`：通过。
- 微信开发者工具 `compile_wxss pages/map/map.wxss`：通过。
- 全屏长下拉：保持触摸并下移 140px 时，`sheetDragOffset=140`、抽屉顶部由 `4px` 跟手移动到 `144px`；松手后 `sheetExpanded=false`，顶部回到半屏 `240.453px`。
- 全屏短下拉：下移 40px 时顶部到 `44px`，松手后保持 `sheetExpanded=true` 并回弹至 `4px`。
- 手势反向：先下拉 140px 再在同一触摸中推回起点，`sheetDragOffset` 跟随回到 0，松手后保持全屏且顶部为 `4px`。
