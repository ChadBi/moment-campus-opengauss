## 2. 已完成内容

### 2.1 P0-001：修复 frontend/Dockerfile ARG VITE_API_BASE_URL 缺失

**问题**：`frontend/Dockerfile` 未声明 `ARG VITE_API_BASE_URL`，`deploy/docker-compose.prod.yml:53-54` 传入的构建参数 `VITE_API_BASE_URL: /api/v1` 被静默丢弃，导致 fresh clone 构建的前端 API 地址回退到 `http://localhost:8000/api/v1`，生产部署即坏。

**修复**：在 Dockerfile builder 阶段增加：
```dockerfile
ARG VITE_API_BASE_URL=/api/v1
ENV VITE_API_BASE_URL=$VITE_API_BASE_URL
```

**验证**：
- `npm run build` 通过（1.36s，0 error）
- 构建参数现在可被 Vite 读取（`import.meta.env.VITE_API_BASE_URL` 在 `frontend/src/services/api.ts:6`）
- 默认值 `/api/v1` 保证未传参时也走同源 nginx 反代
