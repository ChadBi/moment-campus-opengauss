# 任务报告：新增地点按钮文字居中修复

## 1. 任务概述

修复地图页和全部地点页“新增地点”按钮中文字视觉偏移的问题。

## 2. 已完成内容

- 排查确认按钮引用了未注册的 `plus` 图标名称。
- 移除地图页和全部地点页中不可见但仍占据宽度的图标节点。
- 保留按钮原有颜色、尺寸、圆角和点击行为，文字改为独立居中布局。

## 3. 未完成内容

暂无。本次只执行与按钮布局直接相关的定向验证，未执行完整全链路测试。

## 4. 实现思路

`miniprogram/components/icon/icon.ts` 中没有 `plus` 图标，只有 `plus-circle`。原按钮中的 `<icon name="plus">` 不生成可见图像，但仍会保留图片组件尺寸，配合 flex 布局把文字向右推移。移除这个无效节点后，按钮只包含文字，并通过既有 `align-items:center` 与 `justify-content:center` 完成几何居中。
