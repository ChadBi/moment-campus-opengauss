- 新账号继续由后端按所选 `school_code` 创建唯一 active membership，同时设置当前学校和注册学校。

- 首页监听 `campusStore.schoolCode` 变化，切校后立即清空旧学校帖子/推荐/热榜，重置分类和刷新节流状态，下一次显示时强制读取新学校内容。

## 4. 实现思路

登录页先通过 `wx.login` 获取微信临时 code，再加载公开学校目录。提交短信验证码时将所选学校 code 传给 `/auth/wechat/sms-login`：后端只在创建新账号时使用该学校，已有账号仍保留原 `user.school_id`。客户端不相信登录页选择结果，而是用登录响应中的 `user.school_id` 反查学校并写入 `campusStore`。个人主页切校则使用既有 `/schools/{code}/join` 一对一切换语义，并同步本地用户状态。
