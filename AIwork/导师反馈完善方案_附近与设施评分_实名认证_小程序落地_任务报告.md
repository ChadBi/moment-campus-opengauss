## 4. 实现思路

- **设施评分**：新建 `LocationReview`（每地点每用户一条，可改可撤回），评分统计由应用服务在写入时重算 `avg_score/rating_count/review_count`，遵循项目「应用服务为唯一写入口」约定，不引入触发器。
- **附近**：用 Haversine 公式计算距离并按距离升序，新增 `GET /locations/nearby` 与 `GET /posts/nearby`，多租户按 `TenantContext` 隔离。
- **实名认证**：轻量「学号 + 校园邮箱」验证码方案，不接人脸/公安接口；验证码 DB 仅存 SHA-256 哈希，一次性、10 分钟限时；dev 环境响应携带验证码保证演示闭环。
- **作者徽标**：author 序列化输出 `is_verified = user.campus_verified`，前端 `VerifiedBadge` 组件在帖子/评论/评价/个人中心作者昵称旁渲染。
- **小程序落地**：生产 API 域名写死为 `https://campus.chaina1.com`，`resolveImageUrl` 统一解析 `/uploads/` 相对路径；文档化合法域名/隐私政策/体验版流程。
