## 1. 任务概述

## 4. 实现思路

1. 先读取 `此刻校园_可演示Demo.html` 与 `tailwind.config.js`、`index.css`、UI 组件（Card/Button/Input/Badge/Avatar），明确可用的设计 token：色系（lake/lamp/grass/sun/ink/paper/mist）、字体（font-display 楷体、font-data 数字）、圆角、阴影、工具类（.eyebrow/.hand-tag/.brand-text/.paper-panel）。
2. 复用已重新设计的 UI 组件接口（Button variant=primary/secondary/text/danger，Card variant=elevated/outlined/filled + padding），避免在页面内重复造样式。
3. 各页面统一引入：
   - 楷体标题（`font-display` + `text-lake`）
   - eyebrow 小标题（"SEARCH"/"NOTIFICATIONS"/"PROFILE"/"JOIN CAMPUS" 等）
   - 装饰性水墨圆环（参考 Demo 中 `.detail-hero::after` 的圆环装饰）
   - hand-tag 标签用于次级信息展示
4. 业务逻辑严格保留：所有 `useAuthStore`、`searchApi`、`notificationsApi`、`usersApi`、`postsApi`、`authApi` 调用与原代码一致；未登录分支、loading、toast、navigate 跳转全部保留。
5. SearchPage 中将 `handleSearch` 改造为可选第二参数 `(e?, kw?)`，以支持热门标签点击触发搜索，同时兼容原有 `<form onSubmit={handleSearch}>` 调用。
