## 4. 实现思路

1. **先阅读后写作**：严格遵循任务要求，先完整阅读项目（根目录 / 后端 / 前端 / docs）再编写文档
2. **所有结论有仓库依据**：每个技术结论都指向具体的配置文件路径、代码目录、类或模块名称
3. **明确区分事实/推测/待确认**：使用【已确认】【推测】【待验证】三种标注
4. **保留并整合已有文档**：未删除任何已有文档，新文档与现有文档交叉引用
5. **文档服务于后续开发**：每个任务都包含涉及文件、前置条件、验收标准，可直接被下一阶段 Agent 执行
6. **跨文档一致性**：5 份文档之间通过编号（doc 18-22）和任务编号（T-A-* 等）建立引用关系
7. **遵循工作规范**：使用 `backend/.venv` 虚拟环境（依据 AGENTS.md），任务报告按 AIWORK_RULES.md 模板编写
