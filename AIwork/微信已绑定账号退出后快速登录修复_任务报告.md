# 任务报告：微信已绑定账号退出后快速登录修复

## 1. 任务概述

修复用户完成微信手机号绑定后退出登录，再次使用同一微信登录仍被要求重新选择学校并绑定手机号的问题。

## 2. 已完成内容

- 新增微信 OpenID 快速登录接口。
- 已绑定微信身份直接签发小程序登录会话，复用原手机号和绑定学校。
- 未绑定微信身份继续进入手机号、短信验证码和学校选择流程。
- 小程序短信绑定提交每次重新获取 `wx.login()` code，支持失败后重试。
- 新增已绑定账号退出后再次登录的回归测试。

## 3. 未完成内容

暂无。

## 4. 实现思路

后端先将微信登录 code 换取 OpenID，再查询 `wechat_miniprogram` 身份记录。查询到有效身份且关联用户存在时直接复用现有登录签发逻辑；只有首次微信身份才返回 `binding_required`，由小程序继续执行手机号短信绑定。前端将两种结果分流，并统一调用学校绑定和缓存同步逻辑。
