## 4. 实现思路

### 前后端分离架构
- 小程序前端（`miniprogram/`）通过 HTTP API 调用后端服务（`backend/`）
- 后端保持不变，新增微信认证 API（`/auth/wechat/` 前缀）
- 多租户隔离通过 `X-School-Code` 请求头实现

### 双读迁移策略
- User 表 `email` 和 `password_hash` 保持 NOT NULL
- 微信登录用户系统自动生成临时邮箱
- 登录时先查 `user_auth_identities`，若无匹配回退到 email_password 校验
- 确保不破坏现有 Web 登录流程

### 小程序工程结构
- 扁平目录结构，与 project.config.json 同级
- services 层封装所有 API 调用
- store 层管理全局状态（认证、校园）
- types 层定义 TypeScript 接口
- components 层存放通用组件（post-card）

### 请求层核心设计
- JWT access_token 自动注入 Authorization 头
- X-School-Code 自动注入（认证接口除外）
- 401 并发刷新锁（单飞锁，防止多次 refresh）
- refresh 失败后清理会话并跳转登录页
- 图片 URL 补全（`/uploads/xxx` → 完整 URL）
