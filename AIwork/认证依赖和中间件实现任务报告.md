# 任务报告：认证依赖和中间件实现

## 1. 任务概述

在 backend/app/ 目录下创建认证相关的依赖函数和请求日志中间件，为后续 API 接口提供用户认证和请求日志记录功能。

## 2. 已完成内容

1. 修改 dependencies.py，添加三个认证依赖函数：
   - get_current_user_optional：可选的当前用户依赖
   - get_current_user：获取当前登录用户
   - get_current_admin：获取当前管理员用户

2. 创建 middleware.py，实现请求日志中间件：
   - RequestLoggingMiddleware：记录请求方法、路径、状态码和耗时

3. 在 main.py 中注册请求日志中间件

## 4. 实现思路

### 认证依赖函数

- 使用 FastAPI 的 HTTPBearer 自动从 Authorization header 提取 Bearer token
- 使用 security.py 中的 decode_token 解码 JWT token
- 验证 token 类型必须是 "access"
- 从 token payload 中提取 user_id（sub 字段）
- 使用 SQLAlchemy async session 查询用户
- 检查用户状态：is_active 和 is_deleted
- get_current_user_optional 返回 None 表示未登录或 token 无效
- get_current_user 依赖 get_current_user_optional，如果为 None 则抛出 401 异常
- get_current_admin 依赖 get_current_user，检查 role == "admin"，否则抛出 403 异常

### 请求日志中间件

- 使用 Starlette 的 BaseHTTPMiddleware
- 在 dispatch 方法中记录请求开始时间
- 调用 call_next 处理请求
- 计算耗时并记录日志：方法、路径、状态码、耗时（毫秒）
- 在响应头中添加 X-Process-Time 字段
