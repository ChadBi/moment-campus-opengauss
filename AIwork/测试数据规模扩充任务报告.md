# 任务报告：测试数据规模扩充（每校 500 帖 + 50 用户）

## 1. 任务概述

针对测试数据量不足的问题，用户要求扩充演示数据：每校至少 500 条有效帖子与 50 个活跃用户；点赞/评论数基于真实社交平台互动比例生成；所有帖子含主题相关评论且评论数量按热度浮动；用户属性完整、跨校分布合理、关联关系准确。现有数据库数据可全部删除，用全新数据填充。

## 4. 实现思路

- **独立脚本而非改造 seed_data.py**：保留手写演示脚本，新增程序化生成器，两脚本共存互不影响（用户已确认）
- **互动建模**：幂律分布（离散分层）模拟真实社交平台——少数热门帖高互动、多数普通帖低互动；点赞率与 点赞:评论 比例对齐常见校园社区数据（约 10% 点赞率、6:1 点赞评论比）
- **数据真实性保障**：likes 表真实填充且与计数严格一致；评论内容按分类模板生成（share/teamup/trade/lost_found/other 各分类独立模板池，含地点/物品/价格占位符）；发帖/点赞/评论用户均取自同校用户池保证关联准确
- **技术细节**：Post 含 Vector(512) 字段，沿用 seed_data 单条 flush 规避 Python 3.14 insertmanyvalues unhashable 兼容问题；每校 commit 一次避免长事务
