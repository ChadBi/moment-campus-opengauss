## 4. 实现思路

采用 Python 的 python-docx 库自动化生成报告，主要设计思路如下：

1. **文档结构设计**：严格遵循课程设计考核说明的要求，包含封面、目录、系统概述、数据库设计各阶段、开发环境、需求分析、功能需求与E-R图、系统设计（概念/模块/逻辑/物理）、系统实现、运行与维护、小结、参考文献、致谢、附录等完整章节。

2. **内容整合**：从 docs 目录下的多份设计文档中提取核心内容，包括：
   - 需求分析与数据字典（24号文档）
   - 概念模型设计（25号文档）
   - 逻辑模型设计（26号文档）
   - 物理模型设计（27号文档）
   - openGauss适配分析（20号文档）
   - 江南大学模拟核心（23号文档）
   - 项目运行与开发环境说明（22号文档）

3. **格式规范**：按照课程设计模板要求设置字体（中文宋体/黑体、英文Times New Roman）、字号（正文小4号、标题逐级递减）、行距（1.5倍）、页边距（上2.5cm下左右2cm）、表格标题在上、图题在下等规范。

4. **内容充实策略**：
   - 每个表格配有详细的文字说明（1-2段）
   - 每个核心界面配有界面介绍 + 核心代码（约10几行）
   - 物理设计部分深入展开表空间、存储引擎、索引、存储过程、触发器、物化视图、分区表、定时任务等8个子主题
   - 需求分析部分包含用户痛点、组织机构图、数据流图、判定表/判定树、数据字典等完整内容
   - 小结部分包含开发收获 + 5个典型问题及解决方法
