# 任务报告：小程序账号安全与订阅入口修复

## 1. 任务概述

排查小程序个人中心中点击“身份管理”“设备管理”后登录态消失的问题，并移除已经废弃的个人中心“订阅管理”入口，保证小程序个人中心与当前产品边界一致。

## 2. 已完成内容

- 修复请求层把所有 `/auth/` 路径误判为公开接口的问题。
- 身份列表和设备会话请求现在会携带 `Authorization` 与 `X-School-Code`。
- 移除个人中心“订阅管理”设置项、导航方法、主包页面注册和页面文件。
- 保留地点详情所需的分类/地点订阅 service；专题订阅入口仍不恢复。
- 后端未重启：检查时本地 `uvicorn` 已在 8000 端口正常运行。

## 3. 未完成内容

本次未重新跑完整发布、互动、通知和地点摘要 E2E；这些链路在此前任务中已有部分记录，仍需按当前分支继续补齐。

## 4. 实现思路

请求层只将登录、注册、刷新、找回密码和微信换票据等明确公开的认证路径列入白名单。登录后的身份与会话接口不再命中白名单，因此会正常注入短期访问令牌；若令牌过期，沿用统一刷新流程，不再因为接口路径前缀误判而清理登录态。
