# 任务报告：微信小程序局域网调试环境启动

## 1. 任务概述

启动“此刻校园”微信小程序与 FastAPI 后端的局域网调试环境，使同一 Wi-Fi 下的手机可以访问电脑上的开发接口。

## 2. 已完成内容

- 使用 `backend/.venv` 和 `APP_ENV=opengauss` 启动后端。
- 后端监听 `0.0.0.0:8000`，局域网地址为 `192.168.3.10:8000`。
- 打开微信开发者工具中的 `miniprogram/` 项目并刷新模拟器。
- 模拟器切换到 `pages/home/home`，配置仍使用 `useLanDebug=true` 与 `urlCheck=false`。
- 验证局域网健康接口、江南大学当前学校接口和分类接口。

## 3. 未完成内容

- Windows 防火墙规则尚未创建，当前普通权限执行 `New-NetFirewallRule` 返回“拒绝访问”。
- 未执行真实手机扫码、登录、地图、发帖等硬件链路。
- 按用户要求停止了完整 pytest、Web build 和小程序完整检查，不将其写成已通过。

## 4. 实现思路

沿用项目既有的 `192.168.3.10` 开发环境地址和微信开发者工具私有配置，不改线上体验版/正式版地址。后端绑定所有网卡，开发者工具负责重新编译小程序；通过局域网 HTTP 请求验证后端确实可达。

## 7. 测试与验证

- 微信开发者工具门禁：版本 `0.3.9` 与 skill 一致，已登录且无需 CLI token。
- 后端监听：`0.0.0.0:8000`。
- `GET http://192.168.3.10:8000/health`：返回 `{"status":"ok"}`。
- `GET /api/v1/schools/current` + `X-School-Code: jiangnan`：返回江南大学、`map_zoom=16`。
- `GET /api/v1/categories`：返回 5 个分类。
- `simulator_refresh` 和 `simulator_open_page pages/home/home`：成功；console 的 error/warn/fail/wxss/compile 检索为空。
- 完整测试按用户要求停止；真实手机端到端验证需要用户在手机上扫码操作。

## 8. 后续建议

1. 用管理员 PowerShell 执行 `AGENTS.md` 中的 `MomentCampus Backend :8000` 防火墙放行命令。
2. 确认手机和电脑连接同一 Wi-Fi 后，在微信开发者工具点击“真机调试”并扫码。
3. 若更换 Wi-Fi，重新查询 IPv4，并同步更新三处 `DEV_LAN_HOST` 后重新编译小程序。
