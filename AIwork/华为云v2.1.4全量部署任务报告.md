## 4. 实现思路

1. 沿用 deploy-huawei skill 的混合部署方案：openGauss 容器 + FastAPI systemd + Nginx 静态托管。
2. 后端代码与前端 dist 用 Compress-Archive 打包为 zip，SCP 上传至 `/tmp/`，服务器端 `unzip -qo` 覆盖对应目录。
3. 数据库重建：`docker exec -e LD_LIBRARY_PATH=/usr/local/opengauss/lib` 调用 gsql 执行 DROP/CREATE。本次实测发现 gsql 仅设 `PGPASSWORD` 会交互式提示并认证失败，需追加 `-W "$GS_PW"`（密码取自容器环境变量 GS_PASSWORD，内存传递不打印）。
4. 环境变量：`_env_prod_new` 由脚本读取服务器现值（DB 密码 / SECRET_KEY）与本地非密钥配置生成；AI/Embedding API Key 仅通过服务器端 `sed` 内存注入，不落任何文档与终端日志；再由 Python 脚本从 `deploy/.env.prod` 展开生成 `backend/.env.prod` 并复制为 `.env.opengauss`（config.py 固定读取该文件）。
5. 数据填充：`generate_bulk_data.py`（含清库逻辑，三校各 505 帖 / 50 用户）+ `generate_embeddings.py --batch-size 50`（1515 条 512 维向量）。
6. 部署中修复 1 个阻断 Bug：迁移文件 `d5e6f7a8b9c1` 缺少 `from typing import Union` 导入，导致 alembic 加载版本文件时 `NameError: name 'Union' is not defined`；本地与服务器同步修复后迁移成功。
