## 4. 实现思路

### 4.1 安全漏洞修复 (SEC-001)

在 `ProtectedRoute` 组件中增强 token 有效性检查：
```typescript
// 增强检查：确保 accessToken 不为 null/undefined/空字符串
const hasValidToken = !!accessToken && accessToken.trim().length > 0;

if (!isAuthenticated || !hasValidToken) {
  return <Navigate to={buildLoginRedirect()} replace />;
}
```

### 4.2 API 路径修复 (API-001)

前后端路径对齐：
- 前端调用：`/admin/governance/reports` → `/admin/reports`
- 后端实现：`/admin/reports`（已正确实现）

### 4.3 异常处理增强 (API-002)

为浏览历史接口添加 try/catch 异常处理：
```python
try:
    # 查询逻辑...
    return PaginatedResponse.create(items=items, ...)
except Exception as e:
    logger.warning(f"Failed to get view history: {str(e)}")
    return PaginatedResponse.create(items=[], total=0, ...)
```
