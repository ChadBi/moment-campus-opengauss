## 4. 实现思路

1. **打包上传**：将 `backend/app`、`backend/scripts`、`backend/alembic`、`frontend/dist` 分别打包为 zip，通过 SCP 上传到服务器 `/tmp/`。
2. **服务器端部署**：通过 SSH 执行命令，解压覆盖对应目录。
3. **数据库重置**：通过 `docker exec` 调用 openGauss 的 `gsql` 工具执行 DROP/CREATE DATABASE。
4. **迁移与种子**：`alembic upgrade head` 执行所有迁移，`seed_data.py` 填充演示数据。
5. **服务管理**：通过 systemd 管理后端（`moment-backend.service`），通过 Nginx 提供 HTTPS 前端和 API 反代。
6. **环境变量**：后端 `.env.prod` 包含生产配置，AI API Key 直接在服务器上更新，不写入任何文档或 Git。
