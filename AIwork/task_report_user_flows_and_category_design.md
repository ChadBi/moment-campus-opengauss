### 2.2 内容与分类设计文档（07_content_and_category_design.md）

**完成内容：**

1. **12 个核心分类详细设计**，每个分类包含：
   - 分类描述
   - 特有字段（字段名、类型、必填、说明）
   - 有效期特点
   - 交互差异
   - 展示重点

2. **通用字段设计**：所有信息共有的 20+ 个字段

3. **标签体系**：
   - 系统预设标签（按分类列出）
   - 用户自定义标签规则
   - 标签使用规则

4. **有效期规则**：
   - 5 种有效期类型（永久、7天、30天、90天、自定义）
   - 各分类默认有效期建议表
   - 过期处理规则（提醒、状态变更、展示调整、用户确认、管理员处理）

5. **分类与类型的区别**：
   - Category（分类）vs PostType（信息类型）的概念对比
   - 信息类型设计（普通、置顶、精选、活动、紧急、聚合）
   - 分类与类型的关系说明
   - 使用场景区分

6. **分类字段差异总表**：用表格展示 12 个分类的特有字段差异

### 9.2 关键设计决策

1. **12 个核心分类**：覆盖校园生活主要场景，既不过于宽泛也不过于细分
2. **有效期分级**：7天/30天/90天/永久，满足不同时效性需求
3. **标签系统**：系统预设 + 用户自定义，平衡标准化和灵活性
4. **分类与类型分离**：分类组织内容，类型控制展示，职责清晰
5. **过期处理机制**：多角色参与（用户确认 + 管理员处理），确保信息质量
