# 任务报告：地点详情弹层与远端接口降级修复

## 1. 任务概述

处理微信小程序地点页两个运行问题：地点卡片点击后详情显示 `Not Found`，以及详情弹层在长列表页面中跟随整页文档底部定位。目标是在远端详情路由尚未部署时仍能打开基础地点信息，并保证弹层固定在当前可见视口。

## 2. 已完成内容

- 复现并确认体验环境 `GET /locations/{id}` 与 `GET /locations/{id}/reviews` 均返回 404；列表接口 `GET /locations` 正常。
- 地点详情请求失败时使用当前学校地点列表中的基础资料降级展示，摘要、稳定资料和评价明细显示为空状态，并给出明确的后端服务提示，不再整块显示 `Not Found`。
- 将页面入场动画从详情弹层的父节点移开，避免 CSS transform 改变 `position: fixed` 的定位基准。
- 详情遮罩改为显式视口四边定位；滚动地点列表后打开详情，弹层仍固定在当前可见页面底部。

## 3. 未完成内容

- 体验环境后端尚未部署地点详情、地点评价和摘要路由，因此真实稳定资料、AI 摘要、评价列表仍需后端部署后才能展示。

## 4. 实现思路

详情数据与评价数据分别请求，任一接口不可用时保留可用内容；详情接口失败则回退到已经通过当前学校列表接口取得的地点对象。弹层使用不带 transform 的页面层作为 fixed 遮罩父级，避免长页面滚动位置影响弹层位置。
