## 4. 实现思路

### 4.1 MapPage chunk 拆分（P2-001）

**问题**：MapPage 单 chunk 1043KB，首次加载缓慢；maplibre-gl 占据绝大部分体积。

**方案**：使用 Vite `manualChunks` 函数（非对象字面量，Rolldown 兼容）将 maplibre-gl 拆为独立 chunk，react-router/react-dom 拆为 react-vendor chunk，lucide-react 拆为 icons chunk。

**关键代码**：
```typescript
manualChunks: (id: string) => {
  if (id.includes('node_modules')) {
    if (id.includes('maplibre-gl')) return 'maplibre-gl';
    if (id.includes('react-router') || id.includes('react-dom') ||
        (id.includes(path.join('react', path.sep)) && !id.includes('react-router')))
      return 'react-vendor';
    if (id.includes('lucide-react')) return 'icons';
  }
  return undefined;
}
```

**结果**：MapPage chunk 16KB（仅含页面逻辑），maplibre-gl 独立 chunk 1MB（按需加载，路由切换时不重复下载）。

### 4.3 401 并发刷新加锁（P2-006）

**问题**：多个请求同时收到 401 时，会并发触发多次 `/auth/refresh`，后端 refresh 接口会签发新 refresh_token 并使旧的失效，导致后续请求拿到已失效 token。

**方案**：引入 `refreshPromise` 单例 promise，首个 401 发起 refresh，其余 401 复用同一 promise；`finally` 清空 promise 保证后续 401 可再次触发。

**关键代码**：
```typescript
let refreshPromise: Promise<string> | null = null;

if (!refreshPromise) {
  refreshPromise = (async () => {
    const response = await axios.post(`${API_BASE_URL}/auth/refresh`, { refresh_token: refreshToken });
    const { access_token, refresh_token: new_refresh_token } = response.data;
    const user = useAuthStore.getState().user;
    if (user) {
      useAuthStore.getState().setAuth(user, access_token, new_refresh_token);
    }
    return access_token;
  })().finally(() => { refreshPromise = null; });
}

const access_token = await refreshPromise;
originalRequest.headers.Authorization = `Bearer ${access_token}`;
return api(originalRequest);
```

### 4.4 logger 封装（P2-007）

**问题**：48 处 `console.error/warn/info` 散落在 21 个文件，生产环境会暴露内部错误信息。

**方案**：新增 `frontend/src/utils/logger.ts`，dev 模式打印完整信息，prod 模式仅 error 打印精简信息（不带 args），warn/info/debug 在 prod 静默。

**关键代码**：
```typescript
export const logger = {
  error: (message: string, ...args: unknown[]): void => {
    if (import.meta.env.DEV) console.error(`[moment-campus] ${message}`, ...args);
    else if (import.meta.env.PROD) console.error(`[moment-campus] ${message}`);
  },
  warn: (message: string, ...args: unknown[]): void => {
    if (import.meta.env.DEV) console.warn(`[moment-campus] ${message}`, ...args);
  },
  info: (message: string, ...args: unknown[]): void => {
    if (import.meta.env.DEV) console.info(`[moment-campus] ${message}`, ...args);
  },
  debug: (message: string, ...args: unknown[]): void => {
    if (import.meta.env.DEV) console.debug(`[moment-campus] ${message}`, ...args);
  },
};
```

### 4.5 多租户动态热门标签（P2-003）

**问题**：SearchPage 的 HOT_TAGS 硬编码为通用列表，切换学校后内容不跟随变化。

**方案**：`useMemo` 从当前学校 categories 派生 top 8（按 sort_order），categories 为空时 fallback 到 FALLBACK_HOT_TAGS。

**关键代码**：
```typescript
const FALLBACK_HOT_TAGS = ['食堂', '图书馆', '自习室', '快递点', '校园活动', '二手', '失物招领', '拍照打卡'];

const hotTags = useMemo(() => {
  if (categories.length === 0) return FALLBACK_HOT_TAGS;
  return categories
    .slice()
    .sort((a, b) => a.sort_order - b.sort_order)
    .slice(0, 8)
    .map((c) => c.name);
}, [categories, currentSchoolId]);
```
