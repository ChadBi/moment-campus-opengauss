## 4. 实现思路

### 4.1 Excel 更新策略
采用「按 sheet 逐项精准更新」而非「整体重写」的策略：
- 使用 `openpyxl` 加载现有 workbook
- 通过 `find_row_by_id` 函数按 ID 列定位行
- 仅更新需要变更的单元格，保留原有格式
- 已修复项标记绿色填充（`C6EFCE`）+ 绿色字体（`006100`）便于视觉识别
- 新增 P2-015 行追加到问题清单末尾

### 4.2 垃圾文件识别策略
采用「三层过滤」识别垃圾文件：
1. **明确过时**：早期 Demo HTML（AGENTS.md 注明）、过时任务清单（被 TODO.md 取代）、旧版检查结果 JSON
2. **临时产物**：E2E 截图（已被正式报告取代）、临时预览文本、临时更新脚本
3. **调试遗留**：backend/*.log、frontend/npm_build.log（均已被 .gitignore 覆盖）

### 4.3 文件移动策略
- **Git 跟踪文件**使用 `git mv`：保留完整 Git 历史，便于追溯和恢复
- **未跟踪文件**使用 `Move-Item`：这些文件原本就被 .gitignore 忽略，普通移动即可
- **不删除任何文件**：全部移动到 `rubbish/`，可随时恢复
- **README.md 纳入版本控制**：作为清理记录长期保留
