# 任务报告：T-X-01 权限矩阵完善

## 1. 任务概述

完善基于角色的权限控制（RBAC），定义 3 种角色层级，提供 `require_role` 依赖工厂与权限矩阵文档，统一全项目的角色校验逻辑。

## 2. 已完成内容

- 新建 `backend/app/core/permissions.py`：
  - 定义 3 种角色常量：`Role.USER` / `Role.ADMIN` / `Role.SUPER_ADMIN`
  - 角色层级映射 `ROLE_LEVEL`（user=1 < admin=2 < super_admin=3）
  - `normalize_role()` 归一化函数（None/空/未知值 → user）
  - `get_role_level()` 获取层级数值
  - `has_role(user, required_role)` 层级判断（高级角色包含低级角色权限）
  - `is_admin()` / `is_super_admin()` 便捷函数
  - `require_role(required_role)` FastAPI 依赖工厂
  - 模块文档字符串内嵌完整权限矩阵（公开/普通用户/管理员/超级管理员接口分类）
- 重构 `backend/app/dependencies.py` `get_current_admin`：改用 `is_admin()`，支持 admin 与 super_admin
- 重构 `backend/app/api/posts.py` `_is_admin`：改用统一权限系统
- 新建 `backend/tests/test_permissions.py`：30 项单元测试，覆盖常量/归一化/层级判断/依赖工厂全部路径

## 3. 未完成内容

暂无。

## 4. 实现思路

采用**层级向下兼容**设计：高级角色自动包含低级角色的全部权限。`require_role("admin")` 同时允许 admin 和 super_admin 通过，避免重复定义。`get_current_admin` 保持向后兼容，内部改用新系统。权限矩阵以文档字符串形式内嵌在 permissions.py 中，便于开发者直接查阅。

- 现有功能完全兼容：172 项测试全部通过

执行 `pytest tests/ -v --tb=short -x`，172 项测试全部通过（含新增 30 项权限测试）。

## 8. 后续建议

- 后续新增管理员接口时优先使用 `Depends(require_role(Role.ADMIN))` 替代 `get_current_admin`
- 如需超级管理员专属功能（如角色分配），使用 `Depends(require_role(Role.SUPER_ADMIN))`
