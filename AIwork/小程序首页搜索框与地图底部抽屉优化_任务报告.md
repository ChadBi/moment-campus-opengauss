# 任务报告：小程序首页搜索框与地图底部抽屉优化

## 1. 任务概述

移除首页顶部重复的搜索入口，并将地图地点详情改造成类似地图软件的底部抽屉：首次点击显示半屏，向上拖拽展开，向下拖拽收起或关闭，同时保证地点详情和相关帖子可以独立滚动。

## 2. 已完成内容

- 删除首页顶部“搜索校园信息...”入口、对应样式和无用跳转方法。
- 首页学校信息栏改为占满顶部可用空间，保留校园地点入口和底部搜索 Tab。
- 地图地点面板增加半屏、全屏两种状态和拖拽手柄。
- 地图抽屉内容改为固定高度的独立 `scroll-view`，可以滚动查看地点资料、摘要和真实相关帖子。
- 抽屉始终避开底部导航栏；上滑展开、下滑收起，再次下滑关闭。
- 切换地点、切换学校和关闭面板时重置抽屉状态，避免旧状态残留。

## 3. 未完成内容

暂无。

## 4. 实现思路

首页只移除重复的页面内搜索入口，不改变底部搜索页和普通搜索能力。地图面板使用固定定位和 flex 布局，半屏状态设置固定视口高度，全屏状态通过上下边界填充可用空间；标题区单独作为拖拽区，正文交给 `scroll-view`，避免拖动正文时被地图抢走手势。拖拽距离超过阈值时按方向切换状态，内容区域不参与抽屉状态切换，因此不会牺牲正常阅读滚动。
