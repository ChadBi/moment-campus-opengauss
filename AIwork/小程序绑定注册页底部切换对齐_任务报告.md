# 任务报告：小程序绑定注册页底部切换对齐

## 1. 任务概述

调整微信绑定/注册页底部“还没有账号？/注册新账号”切换区域，使两段文案作为同一行整体居中并保持视觉基线一致。

## 2. 已完成内容

- 统一模式切换容器的行高、最小高度和垂直居中规则。
- 为提示文案和操作链接设置相同的行高与垂直对齐方式。
- 保持注册/绑定切换、点击区域和文案内容不变。

## 3. 未完成内容

暂无。

## 4. 实现思路

原页面使用 flex 居中，但两个 `text` 节点没有显式行高，字体粗细不同导致开发者工具中出现轻微基线差异。本次在容器和两个文本节点上设置统一的 `40rpx` 行高与垂直对齐，避免通过额外偏移量修正，保证不同模式切换后仍保持一致。
