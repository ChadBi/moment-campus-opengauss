## 4. 实现思路

- **分类色映射**：API 返回的 `category` 仅含 `{ id, name }`，无 slug/code。采用中文名 → 色板键字典（美食→food 等），未知分类降级为 default 灰。Badge 仅 5 个固定 variant，7 色用 inline `style` 承载。
- **hover utility 边界**：`.lift-on-hover` 含 `transition-transform`，仅替换 Header/Sidebar 等简单 transition 场景；Card/Button 用多属性 transition（`transition-[transform,box-shadow,border-color]`），保留 inline 避免冲突。
- **路由 fade**：CSS-only 方案，`key={pathname}` 强制重挂载 wrapper div 触发 `route-fade-enter` 动画，无需 AnimatePresence/framer-motion。`prefers-reduced-motion` 全局规则自动抑制。
- **useInfiniteQuery**：原计划 A5 倾向 useQuery+页码，但"加载更多"是无限滚动语义。useInfiniteQuery 的 `data.pages` 自动累积、`fetchNextPage`/`hasNextPage` 更 idiomatic，append 行为更干净且不丢失已有数据。
