## 4. 实现思路

严格按照 deploy-huawei skill 的混合部署流程执行：

1. **本地打包**：Compress-Archive 分别打包后端 app、scripts、alembic、requirements 和前端 dist
2. **SCP 上传**：上传到服务器 `/tmp/`
3. **服务器更新**：systemctl stop → 解压替换 → 重置数据库 → alembic upgrade → seed_data → 生成 .env.prod → 修正权限 → 重启
4. **验证**：健康检查 → API 接口（登录/帖子列表）→ Nginx HTTPS → 浏览器 E2E
