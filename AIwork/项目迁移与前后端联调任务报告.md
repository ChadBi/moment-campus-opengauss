## 4. 实现思路

1. **环境排查优先**：先确认 Docker、Python、Node 版本，再逐步推进。
2. **分层验证**：数据库 → 后端 API → 前端构建 → 前端 dev → 浏览器联调，逐层确认无误后再进入下一层。
3. **CORS 排查**：联调中发现 GET 请求正常但登录（POST）疑似失败，通过 curl 模拟 CORS preflight（OPTIONS）确认后端 CORS 配置完全正确，排除 CORS 问题。
4. **精确重测**：第一次浏览器测试报告登录失败，经代码审查确认登录逻辑/数据结构/CORS 均无问题后，用更精确的 selector 重新测试，确认登录实际成功（第一次为表单操作不精确导致的误报）。
