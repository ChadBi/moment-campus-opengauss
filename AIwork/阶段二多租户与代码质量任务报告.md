## 4. 实现思路

### 4.1 多租户地图适配策略

**核心原则**：保留硬编码作为 fallback，优先使用动态数据。

1. **中心点/缩放**：store 优先，FALLBACK 兜底
   - `useCampusStore.currentSchoolCenter` 为 null 时（如未登录或 store 未初始化）使用江南大学坐标兜底
   - 使用 `useMemo` 包装避免引用抖动
   - 使用 ref 保存最新值，让初始化 useEffect（依赖空数组）能读取最新值

2. **分类列表**：API 优先，硬编码兜底
   - 切换学校时通过 `currentSchoolId` 依赖重新拉取
   - API 失败或返回空时，fallback 到 `CATEGORY_NAMES` 保证 UI 不空白
   - 颜色映射 `CATEGORY_COLORS` 与分类 id 解耦，作为视觉差异化 fallback

3. **学校切换响应**：新增独立 useEffect 监听 `currentSchoolCenter`/`currentSchoolZoom`
   - 触发 `flyTo` 平滑过渡（800ms）
   - 延迟 850ms 后主动拉取新区域 markers（moveend 事件作为兜底）

### 4.2 关键决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| ESLint set-state-in-effect 处理 | 接受为 warning | 项目 ESLint 配置已显式降级，注释说明是合法用法；全量迁移 React Query 工作量超阶段二范围 |
| 收藏死代码核查 | 不删除注释引用 | `validation_record.py:34` 注释引用迁移脚本名是合理的历史记录，非死代码 |
| auth.py 日志修复方式 | DEBUG + token 前 8 位 | 既保留排查能力（token 前缀匹配），又避免明文泄露；生产 LOG_LEVEL=INFO 时不输出 |
| MapPage 分类颜色 | 保留硬编码作为 fallback | 颜色与分类 id 解耦，未命中回退灰色；后端不返回颜色字段，硬编码是合理设计 |
