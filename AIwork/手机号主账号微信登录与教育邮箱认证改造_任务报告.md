# 手机号主账号微信登录与教育邮箱认证改造——任务报告

## 1. 任务概述

将原有邮箱/密码注册登录与微信邮箱绑定流程改为手机号主账号体系：Web 支持手机号短信/密码登录，小程序使用微信手机号授权直接登录，教育邮箱独立承担校园认证。

## 2. 已完成内容

- 新增手机号唯一业务键、教育邮箱唯一字段、可空密码和短信验证记录表及 Alembic 迁移。
- 实现 Mock SMS Provider 与阿里云 SMS Provider，验证码 6 位、5 分钟有效、60 秒发送间隔，数据库不保存明文验证码。
- 实现手机号注册、短信登录、密码登录、一次性设置密码和废弃邮箱找回密码入口。
- 实现微信手机号自动建号/登录、微信身份保留和手机号账号合并处理。
- 实现教育邮箱提交、邮件验证码确认、唯一绑定和手机号短信确认解绑。
- 完成 Web 登录/注册/个人中心和小程序登录/个人中心界面改造。
- 清空并重建 openGauss 三校演示数据；新注册账号默认未认证。

## 3. 未完成内容

暂无本次计划内的功能性未完成项。后端全量测试按用户最新要求未执行，详见第 7 节。

## 4. 实现说明

`users.id` 保留为物理主键，`users.phone` 为业务唯一身份。历史 `users.email` 列仅保留用于数据兼容，不被认证接口查询；历史 `email_password` 身份记录由迁移清理，微信 `wechat_miniprogram` 身份记录保留。微信生产流程调用微信 code2Session、access_token 和 getuserphonenumber 接口，未配置密钥时使用固定 Mock 手机号。

教育邮箱认证继续限定注册学校域名，并通过 `education_email` 唯一索引保证一对一绑定。解绑先走手机号短信用途 `education_unbind`，成功后清除邮箱和认证状态。

## 6. 影响范围

登录凭证由邮箱变为手机号；旧邮箱登录、邮箱注册、邮箱找回密码和微信邮箱绑定不再有效。教育邮箱不再决定登录身份，只影响校园认证徽标。管理员用户列表改为展示脱敏手机号和教育邮箱状态。现有内容、学校切换、角色权限、帖子状态机和跨校只读规则保持不变。
