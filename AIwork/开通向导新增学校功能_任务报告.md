# 任务报告：开通向导新增学校功能上线

## 1. 任务概述

修复学校开通功能入口缺失问题——在开通向导页面新增「快速创建学校」入口，使超管可以在开通流程中直接创建新学校，无需先跳转到学校管理页面，完善整体开通体验。

## 2. 已完成内容

1. 在开通向导（SchoolImportPage）页面步骤1「选择或创建学校」卡片头部添加「新增学校」主按钮
2. 实现「快速创建学校」弹窗，包含核心字段：
   - 学校代码（必填）
   - 学校名称（必填）
   - 省份、城市、详细地址（可选）
   - 中心纬度、中心经度、地图缩放（可选，默认zoom=16）
3. 添加友好提示：Logo、品牌色、套餐分配、管理员邮箱等非必要字段可在「学校管理」页面后续完善
4. 创建成功后自动刷新学校列表并自动选中新创建的学校，可直接继续后续开通流程
5. 添加空状态引导：平台暂无学校时显示提示，引导用户点击按钮创建第一所学校
6. 更新页面流程描述为「新增学校 → 下载模板 → 上传 CSV → 预览校验 → 批量导入」
7. 修复无关TypeScript错误：移除 AdminLocationsPage.tsx 中未使用的 Info 导入
8. 浏览器端到端验证：

   - 开通向导页面「新增学校」按钮正常显示，弹窗正常打开

9. 前端构建验证：`npm run build` 成功通过

## 4. 实现思路

在开通向导页面中复用平台API的 `createSchool` 接口，添加轻量化的快速创建表单：
- 仅收集开通流程必要的核心字段（代码、名称、地理位置），非必要字段（Logo、品牌色、套餐、管理员邮箱）留到学校管理页面完善
- 创建成功后自动刷新列表并选中新学校，让开通流程连贯不中断
- 保持和学校管理页面新增学校一致的后端逻辑（自动复制默认分类、创建默认设置、分配trial套餐、写入审计日志）
- 下拉选择学校时显示暂停状态标记，避免误选已暂停学校
