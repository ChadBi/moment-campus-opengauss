## 4. 实现思路

### 4.1 TypeScript strict 渐进启用策略

按计划 §6.2 决策项「先 strictNullChecks，分阶段降低类型错误」：
1. 仅开启 `strictNullChecks` + `noImplicitAny` 两项（不一次开启完整 `strict: true`）；
2. 运行 `npx tsc --noEmit -p tsconfig.app.json` 收集错误；
3. 实际测试发现代码库已兼容（exit 0），无需修复；
4. 通过 `npm run build` 二次验证。

**结果**：代码库类型健康度优于预期，归功于阶段二 P1-004 ESLint 修复时已顺带处理了大部分类型问题。
