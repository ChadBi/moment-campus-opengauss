# 任务报告：学校选择页界面优化与搜索

## 1. 任务概述

优化微信小程序学校选择页的视觉体验，并增加学校搜索栏，让用户可以快速按学校名称、城市、地区、描述或 code 找到目标学校，同时保持现有学校绑定和切换接口不变。

## 2. 已完成内容

- 重做页面头部层级，增加可选学校数量和当前页面语义提示。
- 增加搜索栏、搜索图标、清空按钮、结果数量提示和无结果状态。
- 学校卡片重新调整尺寸、圆角、阴影、Logo、选中边框和确认反馈。
- 底部确认栏增加当前选中学校摘要，优化安全区、阴影和按钮层级。
- 搜索过滤支持学校名称、学校 code、省份、城市和描述，输入时实时更新列表。
- 过滤后再次选择学校时，同时同步完整学校列表和过滤列表，保证选中态与确认栏一致。

## 3. 未完成内容

- 微信开发者工具的 automator 输入接口在当前调试会话中超时，因此未自动输入关键词完成交互断言；用户可手动输入关键词验收。

## 4. 实现思路

页面保留 `schools` 作为完整目录，新增 `filteredSchools` 作为展示列表。搜索输入只改变过滤结果，不改变已选学校；用户点击卡片时更新完整列表中的 selected 状态，再基于当前关键词重新计算展示列表。视觉上使用浅色渐变背景、半透明搜索容器、较紧凑卡片和固定底部 CTA，确保搜索、选择和确认路径连续且清晰。
