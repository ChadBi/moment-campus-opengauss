## 4. 实现思路

- **测试分层**：单元测试只验证 Python 代码逻辑（配置、Schema、依赖、状态机），不触碰 DB；集成测试单独用 `integration` marker 隔离
- **DB 字段同步**：03_alter_tables.sql 在 DB 层添加了 4 个字段，但 ORM 未声明，导致 ORM 插入时缺字段。补全 Mapped 列声明，避免回归
- **openGauss 兼容**：`TRUNCATE TABLE IF EXISTS` 在 openGauss 报语法错误，改用 `DO $$ BEGIN EXECUTE '...'; EXCEPTION WHEN undefined_table THEN NULL; END $$`
- **断言稳健性**：避免硬编码可能被 .env 覆盖的值（如 APP_NAME 改为 `assert "此刻校园" in settings.APP_NAME`），密码字段被 SQLAlchemy mask 为 `***` 改为逐部分断言
