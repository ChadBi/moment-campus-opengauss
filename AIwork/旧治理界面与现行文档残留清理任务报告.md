# 任务报告：旧治理界面与现行文档残留清理

## 1. 任务概述

根据 T1–T8 二次审计结果，清理仍进入当前运行时和现行文档的旧三类治理语义，避免管理员页面错误解释正式举报 API。

## 2. 已完成内容

- 删除重复的管理员协同治理页面及菜单入口。
- 删除前端旧治理报告类型和伪 API 方法。
- 保留旧 `/admin/governance` 地址兼容，并重定向至正式举报管理页面。
- 将 ValidationRecord 模型注释更新为 confirmation/refutation 两类。
- 清理技术架构中的收藏现行口径，更新课程报告的多租户、动态分类、自动过期与维护计划。
- 更新当前质量基线为后端 971 项、Web E2E 38 项。

## 3. 未完成内容

暂无。

## 4. 实现思路

现有 `AdminReportsPage` 已完整实现正式举报枚举和处理动作，而旧 `AdminGovernancePage` 将同一 `/admin/reports` 接口误包装为已删除的 update、expiration_report、conflict_report。采用删除重复实现并兼容重定向的方式，避免维护两套含义冲突的工作台。
