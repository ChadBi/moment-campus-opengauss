# 任务报告：修复帖子图片预览不显示和切换学校后个人主页问题

## 1. 任务概述

修复两个问题：
1. 帖子图片和头像上传后预览不显示
2. 切换学校后，点击个人主页的帖子显示"资源不存在"，要求切换学校后个人主页正确隐藏/刷新跨校数据

## 2. 已完成内容

- 修复后端静态文件路径问题：将`UPLOAD_DIR`从相对路径改为绝对路径
- 修复个人主页切换学校不刷新数据的问题：增加学校变化检测，切换时自动清空旧数据并重新加载
- 更新TODO.md和CHANGELOG记录本次修复

## 3. 未完成内容

暂无。

## 4. 实现思路

**问题一根因**：后端`config.py`中`UPLOAD_DIR = "./uploads"`是相对路径，如果后端启动时的工作目录不是`backend/`（例如从项目根目录启动），会导致：
- 上传文件保存到错误的位置（项目根目录下的uploads/，而不是backend/uploads/）
- 但`main.py`中静态文件挂载的是`os.path.abspath(settings.UPLOAD_DIR)`，如果启动目录不同，挂载路径和上传路径不一致
- 结果是图片/头像上传了，但静态文件服务找不到，返回404

**修复方案**：将`UPLOAD_DIR`改为基于`config.py`所在位置计算的绝对路径（`backend/app/config.py` → `backend/`目录 → `backend/uploads/`），这样无论从哪个目录启动后端，路径都一致。

**问题二根因**：个人主页`profile.ts`中`campusStore.subscribe`回调只更新了学校名称显示，但没有清空旧学校的帖子列表和统计数据，导致：
- 切换到B学校后，个人主页仍显示A学校的帖子（这些帖子ID在B学校不存在）
- 点击这些帖子时，后端按B学校租户校验，发现帖子不属于B学校，返回404"资源不存在"

**修复方案**：在subscribe回调中增加学校变化检测：
1. 记录`_lastSchoolId`，初始为0
2. 每次学校状态更新时，比较新学校ID和上一次的ID
3. 如果ID变化（且不是首次加载），说明用户切换了学校
4. 此时：清空posts/history数组、重置分页（page=1/hasMore=true）、清零统计数字
5. 调用`refreshProfile(true)`强制重新加载当前学校的所有数据

  - 后端所有相关接口（/users/me/posts、/users/me/stats、/users/me/view-history、GET /posts/{post_id}）都已正确按`tenant.school_id`过滤
