# 任务报告：UX-01 用户体验增强

## 1. 任务概述

实现 UX-01 用户体验增强的 7 个子任务，覆盖搜索体验、地图联动、分享、草稿自动保存、通知偏好、PWA 和无障碍优化。本次任务在前期已完成各子功能开发的基础上，修复前端 TypeScript 构建错误并完成全链路验证。

## 2. 已完成内容

### UX-01.1 统一主搜索入口 + 最近搜索 + 已保存查询 + 高频快捷问题
- 最近搜索：localStorage 按学校 code 分键，最多 8 条，点击即搜，支持单条删除与全部清空
- 已保存查询：可命名保存当前筛选条件（普通/AI 模式 + 全部筛选快照），最多 20 条，支持应用与删除
- 高频快捷问题：AI 模式下展示 6 个江南大学场景示例，点击直接发起 AI 搜索
- 普通筛选与 AI 搜索同一结果模型（PostListItem）

### UX-01.2 地图与列表双向联动 + 详情页地址/深链接/导航
- 点击搜索结果跳转 `/map?focus_post_id=xxx` 聚焦地图
- 详情页提供复制地址（含 building/floor 信息）、复制深链接、调用外部地图导航
- 地图不可用时保留文字路径回退

### UX-01.3 系统原生分享 + 链接复制回退
- `navigator.canShare()` 检测原生分享能力，不可用回退复制链接

### UX-01.4 发布表单自动保存草稿

### UX-01.5 通知偏好

## 4. 实现思路

### 搜索体验（UX-01.1）
- 在 SearchPage 中按学校 code 分键管理 localStorage 数据，确保三校隔离
- 最近搜索与已保存查询使用独立存储键，分别管理生命周期
- 应用已保存查询时通过 `pendingSearchRef` + useEffect 延迟触发搜索，确保状态更新完成后再搜索

### 地图联动与详情页（UX-01.2）
- 复用既有 MapPage focusPost 机制（localStorage + 路由跳转）
- 详情页通过 `navigator.clipboard.writeText` 实现地址/深链接复制
- 外部地图导航通过构造 `https://maps.apple.com/?ll=lat,lng` 等 URL 实现

### PWA（UX-01.6）
- Service Worker 仅 precache 应用壳核心资源（HTML/Manifest/Icons），运行时缓存仅针对同源静态资源
- 敏感 API 响应（含 /api/ 路径）一律走网络，不进缓存
- 新版本检测：SW activate 时 postMessage 通知客户端，前端通过 UpdatePrompt 组件提示用户刷新

### 无障碍（UX-01.7）
- 语义化标签：form role="search"、nav aria-label、main tabIndex=-1
- 键盘导航：SchoolSwitcher 实现 combobox 模式（ArrowUp/Down/Home/End/Escape/Tab）
- 错误关联：Input 组件通过 aria-invalid + aria-describedby 关联错误提示
- 焦点可见：所有交互元素添加 focus-visible:ring 样式
- 跳转链接：登录页和后台页添加 sr-only skip link

### 构建错误修复
- SearchPage.tsx 的 TDZ 问题：将 keyword/categoryId/locationId/postTypeId/status/dateFrom/dateTo/sort/aiQuery/aiIntent 等 15 个状态变量声明从组件后方移至 useCallback 上方，同时将 pendingSearchRef 提前声明
- LocationBrief 类型缺失：前后端同步补充 building?: string 和 floor?: string（后端 Location 模型本就有这两个字段，只是 LocationBrief schema 未暴露）
