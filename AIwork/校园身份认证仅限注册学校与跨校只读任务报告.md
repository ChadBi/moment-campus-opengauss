# 任务报告：校园身份认证仅限注册学校与跨校只读

## 1. 任务概述

修正学校切换后的校园身份逻辑：校园认证只对注册时选择的学校开放；切换到其他学校时不清空原认证，但普通用户只能浏览，不能进行内容写操作。

## 2. 已完成内容

- 新增并返回 `registration_school_id`，注册时记录，历史数据迁移回填。
- 切校不再清除 `campus_verified`，认证接口只接受注册学校租户。
- 后端写权限增加跨校只读门禁。
- Web 与小程序隐藏非注册学校的校园认证卡片和个人资料认证标识。
- Web 与小程序的发布、评论、互动、地点评价、地点资料提议和新增地点入口同步显示只读状态。
- 更新 TODO、CHANGELOG、规则文档和本任务报告。

## 3. 未完成内容

微信开发者工具的 profile/post-detail WXML 单文件编译在本次调用中受到工具频率限制；地点页 WXML 编译已成功，小程序 TypeScript/格式检查已通过。未执行完整全链路测试，符合本任务范围。

## 4. 实现思路

保留 `school_id` 作为当前租户字段，新增不可变的注册学校字段，避免破坏现有多租户查询。后端通过统一校园权限依赖核对当前租户与注册学校；前端使用同一规则计算认证标识和写权限，形成 UI 与接口双重保护。

- 后端：User 模型、UserResponse、注册接口、校园认证接口、权限依赖、学校切换服务、Alembic 迁移、定向测试。
- Web：认证卡片、VerifyGate、发布表单、帖子详情、个人资料、学校切换提示、权限工具和用户类型。
