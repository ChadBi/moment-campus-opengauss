# 任务报告：小程序地图地点详情统一滚动修正

## 1. 任务概述

修正地图地点面板“只有帖子区域滚动”的交互偏差，使地点标题、评分、摘要、相关帖子和详情按钮成为一个连续内容页面，整体滚动体验与首页信息流一致。

## 2. 已完成内容

- 将地点详情标题区放入地点详情 `scroll-view`，不再固定在滚动区域外。
- 将评分、稳定资料、AI 摘要、相关帖子和“查看完整详情”按钮放入同一内容流。
- 保留半屏抽屉与全屏展开状态，展开后整个地点详情页面可连续滚动。
- 取消原先“面板固定外壳 + 帖子局部滚动”的嵌套视觉结构。
- 保留顶部拖拽区、关闭按钮、真实地点帖子查询和学校切换状态保护。

## 3. 未完成内容

暂无。

## 4. 实现思路

地点抽屉仍由外层固定容器控制半屏和全屏高度，但容器内部只保留一个 `scroll-view`。标题区作为滚动内容的第一部分，正文和操作按钮紧随其后，因此滚动时标题会与正文一起离开视口；顶部拖拽区只负责半屏与全屏的状态切换，正文区域交给统一滚动容器处理。
