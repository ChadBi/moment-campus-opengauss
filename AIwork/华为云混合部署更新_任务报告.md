## 4. 实现思路

### 4.1 沿用混合部署方案

参考 `docs/30_华为云混合部署记录.md`（2026-07-05 部署记录），保持以下组件不变：
- **openGauss**：Docker 容器 `moment-opengauss`，仅绑定 `127.0.0.1:5432`
- **后端**：systemd 服务 `moment-backend`，4 uvicorn workers，监听 `127.0.0.1:8000`，运行用户 `moment`
- **前端**：Nginx 静态托管 `/opt/moment-campus/frontend/dist/`
- **Nginx**：HTTP 80 → HTTPS 301 + HTTPS 443 反代 `/api/`、`/docs`、`/health`、`/uploads/`
- **SSL**：Let's Encrypt 证书（到期 2026-10-03，certbot timer 自动续期）
- **Cloudflare**：域名前置代理

**调整方案**：本地构建 → tar 打包 → scp 上传 → 服务器解压。整个过程 < 30s。

## 8. 后续建议

1. **AI 搜索功能启用**：若需启用 AI 搜索，需在 `/opt/moment-campus/backend/.env.prod` 添加 `OPENAI_API_KEY=sk-***` 并 `systemctl restart moment-backend`
2. **演示数据刷新**：若需刷新演示数据（含新增的多租户/订阅/发布主体等表），可 `cd /opt/moment-campus/backend && source .venv/bin/activate && python scripts/seed_data.py`
3. **服务器安装 Node.js**（可选）：若希望服务器能直接 `npm run build`，可 `curl -fsSL https://deb.nodesource.com/setup_20.x | bash - && apt install -y nodejs`，便于后续 CI/CD
4. **Nginx 缓存清理**：Cloudflare 已自动刷新；如发现旧资源缓存，可在 Cloudflare 控制台触发 Purge Everything
5. **数据库备份归档**：当前备份在服务器 `/tmp/` 目录，建议 `mv /tmp/moment_campus_backup_20260728.dump /opt/backup/` 持久化保存
6. **Git stash 恢复**：服务器侧 `deploy/deploy.sh` 和 `deploy/init.sh` 的文件权限修改已 stash，本次部署后未恢复。如需恢复可 `git stash pop`（不影响功能）
7. **限流倍率验证**：可在生产环境用 `ab -n 10 -c 1 https://campus.chaina1.com/api/v1/auth/login` 验证 5/60s 限流仍生效（生产倍率=1）
