# 任务报告：核心页面手绘水墨风重新设计

## 1. 任务概述

将 `frontend/src/pages/` 下的 5 个核心页面（HomePage、LoginPage、MapPage、PublishPage、PostDetailPage）重新设计，使其符合手绘水墨风格，参考 `此刻校园_可演示Demo.html` 的设计语言。要求保持所有业务逻辑、API 调用、状态管理、import 路径与组件接口不变，仅修改 UI 样式；MapPage 需保留全部 MapLibre GL JS 功能逻辑。

## 2. 已完成内容

- **HomePage.tsx**：页面标题用楷体（font-display）"此刻校园" + 副标题"把会消失的校园经验留下来"，配 eyebrow 小标题；信息流卡片用 Card variant=elevated，左侧 Avatar + 右侧内容；卡片标题 font-medium、分类用 Badge；底部统计用小图标 + font-data 数字（浏览/点赞/评论）；加载更多用 Button variant=secondary；空状态用大 emoji（⌖）+ 文字引导。
- **LoginPage.tsx**：居中布局 max-w-[400px]；顶部品牌标志"此"楷体大字（湖蓝 lake 色）置于 paper 圆角方块内，配灯笼橙下弧线装饰（复刻 Demo 的 brand-mark）；标题"欢迎回来"楷体；表单用 Card variant=elevated 包裹；输入框用 Input 组件（带 Mail/Lock 图标）；登录按钮用 Button variant=primary（灯笼橙）size=lg；底部注册链接保留。
- **MapPage.tsx**：顶部工具栏标题"校园生活地图"（楷体）+ 实时状态标签（grass 色 pulse 动画圆点）；分类筛选条横向滚动，"全部"用湖蓝 lake 底 + shadow-lake，分类按钮用各自分类色；地图容器大圆角 23px + .paper-noise 纸张纹理叠加 + border + shadow-md；地图标注弹窗样式调整为手绘风（楷体标题、方角色点、灯笼橙"查看详情"按钮带 shadow-lamp）；缩放/定位控件改为 paper 半透明 + 圆角；**完整保留所有 MapLibre GL JS 逻辑**（mapInstance 初始化、moveend 防抖、markers/popup ref、分类筛选、geolocation、缩放控制、cleanup）。
- **PublishPage.tsx**：标题"发布此刻"楷体；表单用 Card variant=elevated 包裹；表单字段用 Input 组件 + textarea（统一手绘风 focus 样式）；分类选择由原 select 改为手绘风按钮网格（3-4 列，emoji + 名称，选中 lake 底 + shadow-lake），状态字段 formData.category_id 结构保持不变；提交按钮用 Button variant=primary（灯笼橙）；提示信息用淡绿色背景卡片（bg-grass/12 + border-grass/20）。
- **PostDetailPage.tsx**：顶部 hero 区域渐变背景（from-[#cfe3e6] to-[#e9f0d8]）+ 装饰圆环 + 大标题（楷体 font-display）+ 位置信息（MapPin）；信息卡片网格 2 列布局，小卡片展示现在状态/信息分类/有效确认（font-data 数字）/贡献者；内容区域用暖色背景（#fff6ec）的笔记卡片 + hand-tag 标签；作者信息 + 统计用 Card variant=elevated（统计数字 font-data）；底部操作按钮：点赞 primary、收藏 secondary、分享 secondary、举报 text；评论区用 Card variant=elevated，评论标题楷体；空状态/不存在状态用大 emoji 引导。

## 4. 实现思路

1. 先读取 `此刻校园_可演示Demo.html`、`tailwind.config.js`、`src/index.css`、`src/styles/tokens.ts`，明确可用设计 token：色系（lake/lamp/grass/sun/ink/ink-sub/ink-muted/paper/mist/line/danger）、字体（font-display 楷体、font-data 数字）、圆角（rounded-sm 10px / md 14px / lg 20px / xl 28px）、阴影（shadow-sm/md/lg/lamp/lake）、CSS 工具类（.paper-panel/.eyebrow/.hand-tag/.brand-text/.paper-noise）。
2. 读取已重新设计的 UI 组件（Card/Button/Input/Badge/Avatar/Loading/Toast）与布局组件（MainLayout/Header），确认接口与页面渲染上下文（页面在 MainLayout 的 `<main>` 内，已有 Header 全局品牌字），避免与全局导航重复造样式。
3. 各页面统一引入：楷体标题（font-display + text-lake）、eyebrow 小标题、font-data 数字、hand-tag 标签、装饰性圆环（参考 Demo `.detail-hero::after`）。
4. 业务逻辑严格保留：所有 `postsApi`/`authApi`/`commentsApi`/`interactionsApi`/`mapApi` 调用、`useAuthStore`/`useNavigate`/`useParams`、useState/useEffect/useRef/useCallback、表单校验、loading/toast/跳转逻辑全部与原代码一致；PublishPage 的分类选择虽由 select 改为按钮，但 `formData.category_id` 状态结构与 `handleSubmit` 校验逻辑保持不变。
5. MapPage 重点处理：将原绝对定位筛选条改为 flex-col 布局（工具栏 + 筛选条 + 地图容器），地图容器加 23px 圆角与 .paper-noise 叠层；标记创建逻辑（DOM 元素 + cssText）与弹窗创建逻辑（setDOMContent + click 跳转）原样保留，仅替换弹窗 innerHTML 的样式字符串为手绘风。
6. PostDetailPage 的 4 个信息小卡片字段映射到实际 Post 类型可用字段：现在状态→post.status、信息分类→post.category?.name、有效确认→post.valid_count、贡献者→post.author?.nickname（Demo 中的 price 字段在 Post 类型中不存在，改用"信息分类"替代）。
