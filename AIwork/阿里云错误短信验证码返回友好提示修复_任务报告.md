# 任务报告：阿里云错误短信验证码返回友好提示修复

## 1. 任务概述

修复真实测试中用户填写错误短信验证码后，小程序显示“服务器内部错误”的问题。

## 2. 已完成内容

- 识别阿里云 `isv.ValidateFail` / “验证失败”异常。
- 将错误验证码转换为 400“验证码错误”。
- 将其他短信核验异常转换为可重试的短信服务错误，不再返回 500。
- 增加阿里云 Provider 异常分支回归测试。

## 4. 实现思路

阿里云 `CheckSmsVerifyCode` 在部分错误验证码场景不会返回普通失败结果，而是直接由 SDK 抛出异常。短信服务层捕获核验异常，按错误码区分用户输入错误和 Provider 服务异常，再统一转换为业务层的 HTTP 400 提示。
