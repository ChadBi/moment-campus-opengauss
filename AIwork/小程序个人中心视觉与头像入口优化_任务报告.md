# 任务报告：小程序个人中心视觉与头像入口优化

## 1. 任务概述

修复个人中心顶部头像相机按钮漂移、加入时间图标与文字不对齐、当前学校内容贴住两侧边框、推荐隐私标题布局缺失以及顶部渐变背景观感不佳等问题。

## 2. 已完成内容

- 个人资料头部由渐变背景改为稳定的墨青纯色，提升白色文字和认证徽标的可读性。
- 为头像增加相对定位容器，将相机按钮固定到头像右下角；按钮接入 `wx.chooseMedia`，可从相册或相机选择头像并上传到 `/users/me/avatar`。
- 上传中显示刷新图标和禁用态，成功后同步页面头像与 `authStore` 用户信息。
- 加入时间行改为 flex 布局，时钟图标、间距和文字基线统一。
- 当前学校行改为内缩的浅湖蓝圆角卡片，避免背景和内容直接顶住外层边框。
- 当前学校、校园认证、推荐隐私的标题图标统一使用图标底座；推荐隐私补齐标题行的内边距、分隔线和控件对齐。

## 3. 未完成内容

- 尚未在真实手机上选择并上传一张头像；模拟器仅完成布局和编译验证。
- 头像上传仍受后端上传目录和局域网地址影响，真机调试时需确保手机可以访问当前开发机的 8000 端口。

## 4. 实现思路

先复现截图，确认相机按钮只有 WXML 没有对应 CSS 和 `onAvatarTap` 方法，导致它按普通流布局掉到头像下方。随后补齐头像定位与上传闭环。对于学校和推荐区域，保留原有信息结构，只调整容器边界、标题图标槽位和对齐规则，避免改变个人中心业务流程。
