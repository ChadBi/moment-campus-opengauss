## 4. 实现思路

1. **按优先级分层修复**：先修复地图交互稳定性（影响演示核心体验），再处理 500 兜底、AI 摘要删除、举报类型等业务逻辑，最后做说明性调整（专题/任务记录/治理工作台）。
2. **尽量删除而非兼容**：发布主体功能整体删除，前后端路由/测试文件一并清理，而非保留死代码；`PostForm.tsx` 中 `PostTemplate` 类型同步改为真实使用的 `PostTemplateListItem`。
3. **地图稳定优先交互限制**：不引入复杂算法，先禁用旋转/倾斜/双击缩放，解决 90% 的竖直漂移；`MapLocationPicker` 使用 wheel 节流 + `zoomTo` 缓冲解决抽搐。
4. **错误兜底最小侵入**：`create_post` 仅在 `db.commit()` 外围加 try/except，回滚后转为 400 级 `BadRequestException`，不改变业务主流程。
5. **多帖面板与单帖统一路径**：避免两种 UI 形态并存，直接复用侧滑面板；通过 `groupedMarkersRef` 暂存聚合数据供面板渲染。
6. **摘要删除保持向后兼容**：后端 `AIPublishSuggestions` schema 仍保留 summary 字段（Pydantic 可缺省），但恒定返回 `None`，前端直接跳过渲染。
